# 差点后期｜使用说明与验收

版本：v2 · 分阶段逐镜头版 · 2026-09-05

本次更新针对插座测试中的越阶段制作、镜头分析过粗、提示词缺失、封面文字与构图失控、编辑工程功能缩水。已按用户纠正落实：**允许少量有用、准确的小字；禁止最终大标题、占位标题、乱码和杂乱无关的字。**

## 安装与开始使用

1. 解压ZIP，以 `01_项目指令.md` 正文替换 Project Instructions。
2. 用 `来源` 内10个【差点】Markdown替换旧来源。项目中只保留这一套活动规则，避免旧 Lite/Mini 或v1同时参与检索。
3. 本说明只用于安装与验收，不上传为项目来源。在该Project新聊天粘贴文案即可，默认先完成分析。

共12个Markdown：指令1个、正式来源10个、说明1个；加ZIP为13个交付文件。此次更新的是文件包，尚未替用户修改Project设置。

【差点】文件是来源与能力分工，文件名本身不会启动另一个智能体。每次进入能力要实际读来源，并给出依据章节、本次3–5条约束及交付摘要；读取不到要说明。实际工具能力仍取决于当前聊天环境。

## 新流程与常用指令

A是全文分析，B是指定镜头设计，C是指定制作，D是验收与改稿。阶段字母与SHOT-B/A/S投入等级是两套不同标记。

| 你的输入 | 本轮应交付 | 停止位置 |
|---|---|---|
| 粘贴全文，含（素材）（CGI）等标注 | 全文逻辑、全篇镜头总览、逐镜头八项分析卡、待核/待决定项 | 分析结束，不外搜、不生成、不编码 |
| 展开03 / 设计03 | S03完整设计卡；生成类附完整提示词 | 设计待审 |
| 设计封面 | 卖点与冲突、横竖构图和标题区、小字清单、两版完整提示词 | 设计待审，不直接出图 |
| 确认 / 可以 | 锁定当前方案和保留项 | 已确认待制作 |
| 按确认方案制作03 | 完成S03约定成果并检查 | 不带做其他镜头 |
| 找03素材 / 核验这条数据 | 执行指定搜索或核验任务 | 不扩展成整片制作 |
| 不好看 | 最多三个具体问题、保留项、改法 | 修改方案待审 |
| 按方案改图 / 只改03的颜色 | 执行明确修改范围 | 保留未撤销约束 |
| 直接生成横竖两版，无需确认 | 先公开简短方案与两版完整提示词，再制作双版 | 不附赠未要求的其他方案 |

“继续”：分析未完就续分析；分析完成则设计第一个未设计镜头；设计未完就补齐；设计已齐但没有制作指令时说明已就绪并提供“制作03/下一镜”入口。已授权制作批次内只续该批次。长文可以每批展开3–5张分析卡，但必须保留全篇索引，不能先生产前几个镜头。

## 这次真实测试暴露了什么

依据用户上传的《插座封面_完整对话记录_2026-09-05.zip》，检查了对话、7张图片及HTML源码。记录没有完整内部工具日志，不能据此断言模型从未读取技能；能确认的是交付缺少可核对的来源落实、提示词和稳定约束。

| 观察到的问题 | 对应修正 |
|---|---|
| 首轮就检索事实、组织镜头并产出约24秒HTML，补入原文外统计信息 | A只分析，疑点待核；核验与制作按指定任务进入 |
| 逐镜头内容主要压在总览表里 | 总览后必须逐镜头八项卡；再按指定镜头展开设计 |
| 7张封面中5张出现最终大标题；后续不满意反馈又回到大标题 | 文字策略进入保留项，改稿不能丢失 |
| 没有大标题的版本仍堆了多国物件、地图与旅行装饰 | 单一冲突、一个主体组，先减元素与改层级 |
| 对话未给出完整可复制封面提示词 | B必交横竖两版Prompt，C生成前也必须可取用 |
| 部分图比例偏离目标，例如1536×1024为3:2、1312×1199接近方形 | 报告实际尺寸，分别适配与查看双版，不靠名称声称比例正确 |
| HTML仅少量标签可改，缺图层/可编辑关键帧/完整工程保存等功能 | 把承诺功能对应到实际可执行验收动作；未运行标未测 |

HTML问题来自源码检查，本次未在浏览器宿主逐项运行该工程；没有把这次文档修改称为已修复原HTML或已改善实际生成图质量。

## 首轮输出示例：分析卡应具体到什么程度

以下是虚构的抽象关系文案，仅演示结构，不制作素材或工程。

> 两个独立模块逐渐靠近，最后连接成一个整体。（动效）

`A｜S01｜分析v1｜全文逻辑与镜头分析`

全文理解：表达“独立→连接”的关系变化；视觉重点在连接成立的一刻，一镜完成即可。

| 编号 | 原文范围 | 核心关系 | 主媒介/能力 | SHOT | 状态 |
|---|---|---|---|---|---|
| S01 | 全句 | 分离到连接 | 动效；视觉辅助 | A | 分析待审 |

1. **原文**：两个独立模块逐渐靠近，最后连接成一个整体。（动效）
2. **表达目标**：观众看懂两个模块从彼此独立变为有明确连接关系的整体。
3. **主视觉**：一组两个几何模块；身份、大小保持稳定，用一个连接点表达关系，不额外画芯片结构。
4. **构图**：正面观察，模块居中左右分离；连接点位于视觉中心，背景保持低对比。
5. **动作**：短暂分离停留→沿共同轴线靠近→连接点出现并停留；背景不另做运动。
6. **媒介/能力/风格**：按标注选动效，视觉负责主次；初选002的清楚说明板布局，具体母版留到设计阶段落实。
7. **投入/时长/画幅**：SHOT-A，定制一个关系即可；建议约4秒，属无音频条件下的估时；16:9横向摆放，1183×1080缩短两侧距离，保持模块大小可读。
8. **待核/待定**：当前按抽象关系示意，不对应真实产品结构；若实际文案指具体模块，需要其身份或参考再定设计。

`本轮已完成：S01分析｜待决定：抽象示意或具体产品｜下一步：展开01`

此处结束。示例不附搜索结果、Prompt或HTML，完整设计与所需Prompt在B交付。
