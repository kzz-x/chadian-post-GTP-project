# 差点后期｜使用说明与验收

版本：2026-09-05 · Project 最终重构版。包含本次新增的横竖封面标题区示意要求。

## 如何使用

1. 解压完整 ZIP，将 `01_项目指令.md` 的正文粘贴到 Project Instructions。
2. 将 `来源` 文件夹内 **10 个【差点】Markdown** 上传为项目来源。
3. 在该 Project 新建聊天，直接粘贴全文或上传文案；在相关段落后写（素材）（元素）（片段）（动效）（CGI）等标注即可覆盖自动判断。
4. 指令与来源只保留这一套活动版本，避免旧 Lite/Mini 与新规则并列互相竞争。旧文件可自行归档留存。

本说明用于安装和验收，不必上传为项目来源。ZIP 内共 12 个 Markdown：项目指令 1 个、正式来源 10 个、本说明 1 个；没有单独的图表或画幅文件。

`【差点】` 文件名是能力检索入口，不是启动另一个 GPT 的命令。项目可以据此组织工作；真实搜索、文件处理、生图、生视频、代码运行仍取决于当前聊天提供的工具与权限。这套文件已完成文档检查和路由推演，尚未在用户新建 Project 中用真实文案完成端到端生产验证。
