# 012｜数据粒子装置

- **适用**：AI 数据、模型训练、网络节点、信息聚合、音乐化开场、抽象数据转场。
- **核心视觉公式**：黑色舞台＋有明确聚散逻辑的点云/碎片＋一个可识别装置或形态。
- **构图**：密集核心与稀疏空间有对比，点线围绕一个形体组织；避免满屏均匀撒点。
- **色彩**：黑底、白/青/绿等少量色系，强调色标定状态；大面积发光要受控。
- **材质**：点、线、薄片和少量文字碎片，不假装所有粒子都是写实玻璃球；颗粒尺度统一。
- **光线**：粒子有限自发光，Bloom 不吞轮廓；暗场仍能区分前后层级。
- **排版 / 图形**：Orbitron/等宽数字可作小标签，必要真实数据单独排；文字环仅在承载概念时使用。
- **镜头**：固定舞台或轻角度观察，让形体形成过程可读；不同时高速旋转装置和摄影机。
- **动态**：聚合→一次脉冲/状态变化→重组或停留，分阶段突出一个主动作；节拍服务主题。
- **禁忌**：所有点永久乱飞、闪烁淹没主体、随机波形、信息无关的数字雨、粒子数冒充统计量。
- **AI 生成约束**：锁主要形态与聚散方向；抽象点云不充当真实测量。代码实现需固定随机种子并支持按时间重建；AI 视频减少同时复杂动作。
