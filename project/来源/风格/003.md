# 003｜纸面档案蓝图

- **适用**：历史资料、证据链、故障复盘、技术拆解、事件时间线、图纸说明。
- **核心视觉公式**：纸面资料＋工程线稿/蓝图＋克制红笔批注，让观众跟着证据和关系阅读。
- **构图**：一份主资料或一张主图，周边证据从属；卡片、批注与连线形成可追踪路径，不做无中心资料墙。
- **色彩**：纸白/浅黄、灰蓝、黑色细线，少量红色用于圈定与连接；不强制全部泛黄成古董。
- **材质**：纸纤维、复印颗粒、轻胶带/折痕、图纸网格按需使用；真实截图清楚，纸张厚度和边缘统一。
- **光线**：俯拍/扫描式均匀光，轻纸面接触阴影；资料文字区避免强反光和深暗角。
- **排版 / 图形**：打字机/等宽小标签与清楚中文黑体，工程标线和红笔批注分工；证据内容必须真实可追溯。
- **镜头**：正俯视或轻倾角，定位式推进/平移，不用复杂景深和三维环绕。
- **动态**：纸卡进入→扫描揭示→红框锁定/连线→结论停留；先显示证据再显示推断。
- **禁忌**：伪造论文新闻、满纸乱码、过量污渍、霓虹玻璃、恐怖犯罪墙、每张纸都贴胶带。
- **AI 生成约束**：可生成空白档案底板与非事实性道具；真实文献/新闻需原图后合成。纸张不能融化，红线两端明确，不产生虚假证据印象。
