# 008｜暗黑超现实能量场

- **适用**：风险、未知技术、行业危机、巨大力量与个体关系的概念开场/封面。
- **核心视觉公式**：巨大自然/宇宙形态＋微小孤立主体＋少量光线，靠尺度与空域建立压迫和未知。
- **构图**：巨大形体与小主体的距离关系明确；负空间和前后层次服务尺度，不能只剩黑底发光圆环。
- **色彩**：近黑为主，深蓝、暗红、暗紫按主题择一；白/蓝/红微量亮点引导视线，暗部不全死黑。
- **材质**：雾、水、云、岩石或抽象有机体按情境选择，保持一套物理/艺术逻辑，不把所有材料混在一起。
- **光线**：低调背光或局部强源，有限体积层揭示体量；主体轮廓可读，能量亮度集中。
- **排版 / 图形**：标签极少，必要字使用清楚重体/衬线；不叠参数 HUD 破坏未知空间。
- **镜头**：广景、慢推/慢拉、低频尺度揭示；稳定地让观众理解相对位置。
- **动态**：一次主要能量涌动或缓慢扩散，小主体动作极少；不是满屏爆炸与相机震动。
- **禁忌**：糖果霓虹、英雄游戏海报、持续闪电粒子、糊雾掩盖几何、无明确主体的黑屏。
- **AI 生成约束**：巨大形态与小主体数量/位置连续；标为概念隐喻，不能当真实灾难或技术实拍。暗部也要有可见层次。
