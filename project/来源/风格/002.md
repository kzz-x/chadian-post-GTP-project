# 002｜蓝白界面说明板

- **适用**：功能教程、软件机制、流程拆解、产品卖点、清爽数据说明。
- **核心视觉公式**：蓝白底＋少量说明卡＋一条清楚关系路径，像精心设计的产品说明界面。
- **构图**：主体/关键步骤明确，通常两到四个信息单元；统一对齐和边距，空白用于分组而不是空洞。
- **色彩**：白、冰蓝、浅灰主导，清晰的蓝色作主要强调，饱和蓝占比克制；警告色只在确有状态差异时出现。
- **材质**：薄磨砂、浅色塑料或轻纸面，轻层叠和细阴影；不要厚重透明水晶。
- **光线**：柔和均匀的屏幕/棚拍式亮度，文字与线条反差足够；弱接触阴影分层。
- **排版 / 图形**：Inter/思源黑体等清晰无衬线，等宽数字；短标签、箭头、步骤号统一，真 UI 用真实参考。
- **镜头**：正视固定；必要局部放大明确定位后返回，不加浅景深糊掉周边步骤。
- **动态**：卡片进入→路径生长/光标指向→状态切换→停留。缓动轻而准确，不让全部单元同时弹跳。
- **禁忌**：大范围故障、强酸色、密集 HUD、厚重金属、无意义镜头绕行、极细低对比小字。
- **AI 生成约束**：生成只负责可用底板/概念图形，精确步骤和文字后排；界面不得冒充某软件实际功能或真实操作记录。
