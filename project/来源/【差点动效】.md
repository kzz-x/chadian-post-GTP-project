# 【差点动效】

- **负责什么**：文字/参数、结构/流程、时间线、产品信息、数据图表、三维/伪三维信息动画，以及 HTML、VibeMotion、Remotion、AE 的可编辑工程。原【差点图表】合并于此。
- **何时调用**：核心是信息关系随时间展开；需要精确数值、可改文字、可控节奏、图层和可复用模板。
- **何时不要调用**：真实拍摄素材交素材；纯完整 AI 场景交片段；普通字幕可直接用既有模板，不为一段字幕重建编辑器。
- **常见触发词**：动效、参数、跑分、市占率、销量、功耗、帧率、流程、时间线、图表、HTML、VibeMotion、Remotion、AE。
- **输入**：文案/数据及来源、静态母版、资产、风格编号、时长、目标画幅、工程环境、修改范围。
- **输出**：B交静态/动态设计、工程功能约定与验证办法；C交可编辑/可复用/可保存工程、实际预览、配置和已测/未测范围。


## 阶段与固定交付

按【差点后期】阶段控制。A只做镜头分析；B交设计与功能约定，不能“顺手做HTML”。C才使用下文工程流程。设计阶段保留未核数据，不自行新增统计事实或改口播；正式图表前做获授权的必要核验。

B固定设计卡：`镜头号/目标｜依据来源/约束｜静态布局与读图顺序｜主次图层｜数据/单位/口径与来源缺口｜起始/变化/终态/停留｜画幅重排｜资产与技术路线｜必须可改的项目｜保存/重开方式｜实际验证办法`。如有用户母版先复用。代码工具可用不代表该阶段可以编码。

C交当前镜头工程，不拼成未要求的整片演示。保持约定功能，不能因“先快速做一个”自行删图层/关键帧/保存能力。做不到时报告未完成，并提出用户可选的调整；不能把缩水demo标成已通过的编辑工程。

### 工程交付逐项对照

| 必须实现的能力 | 实际可验证动作 | 不能用什么冒充 |
|---|---|---|
| 内容/视觉编辑 | 修改真实文字、数据、色彩与本镜头必要布局，预览同步变化 | 只有国家名和一个数字的四个文本框 |
| 图层管理 | 对实际图层改显示、位置、比例、旋转、透明度、层级/轴心 | 页面布局固定，仅改文案 |
| 时间轴/关键帧 | 对实际动画属性改时间和值；播放与seek一致 | 只有播放/拖动进度条 |
| 保存当前工程 | 导出可重开HTML或完整工程包；重开恢复配置、图层、关键帧 | 仅localStorage或只能恢复标签的JSON |
| 数据配置 | 来源/口径/时间/单位与原值集中，改值不造成标签与图形分离 | 只把几个标签叫dataConfig |
| 导入与撤销重做 | 导入承诺的完整状态，编辑可回退/恢复 | 导出包含时间参数，导入却静默忽略 |
| 画幅与手机 | 切布局不挤小字，窄屏可操作，控件不只靠键盘/hover | 写一个画幅下拉菜单但未查看实际画面 |
| clean capture | 只显示正确比例的成品区，可退出；导出无控件/辅助线 | 把画布硬拉成任意屏幕宽高 |

制作前用本表确定本镜头实际适用的内容，制作后按实际运行记录通过/失败/未测。没有宿主工具就明确未实测，不勾选“全部通过”。复杂高级附加功能可以不新建，核心已承诺能力不能降级。

## 1. 制作顺序

**静态构图 → 动画 → 必要运镜 → 最后材质 / 粒子 / 光效。**

先确定观众应读到的结论，选恰当图形与布局；先让静帧成立，再按口播把信息分批交给观众。每次只推进一个主动作，其他层保持或弱化。只有“局部定位、关系揭示、空间尺度”需要时才加摄影机运动；不能为了科技感默认 Three.js。

读取【差点视觉】解决关系与主次，读取【差点风格】对应卡确定视觉。已批准设计稿或工程优先继承，改内容时不随意换布局、字体、图层系统和技术框架。B先交具体设计和技术选择、图层/控件/时间轴/保存约定后停止；只有“按方案制作”等明确指令才进入C编码。

B 镜头改成熟模板即可；A 镜头定制一个关系；S 镜头只把预算花在一个主视觉上。装饰层关闭后，核心信息和布局必须仍成立。

## 2. 选最小有效技术路线

| 任务 | 默认路线 | 何时升级 |
|---|---|---|
| 参数卡、文字、常规流程、少量图形 | HTML/CSS/SVG＋一套时间轴库 | 大量对象再考虑 Canvas |
| 精确自定义图表 | SVG＋D3 比例尺/路径，或可主题化图表库 | 数据量/性能确有需要才换 Canvas |
| 大量二维点线、粒子、滤镜 | Canvas/Pixi 等已有合适实现 | 确需空间透视才用三维 |
| 爆炸结构、空间路径、真正三维关系 | Three.js；已有 React 项目可用 R3F/drei | 不为一层玻璃背景引入整套三维框架 |
| 程序化批量视频/稳定逐帧输出 | Remotion 或现有逐帧渲染方案 | 不把浏览器实时录制当唯一生产链 |
| 用户明确需要 AE | 可编辑 AE 工程/脚本，原生形状、文本、空对象与表达式 | 插件确有必要且用户可用才依赖 |

GSAP 适合主时间轴，Motion 适合已有 React 组件，Anime.js 适合轻量 DOM/SVG；三者不无故叠加。成熟图表库经过定制且满足视觉与可控性，可直接用于最终成品，无需为了“高级”全重写。详细入口见【差点资产】。

## 3. 数据图表规则

### 3.1 先验证数据再设计

至少记录：来源、原始值、单位、时间、地区/人群/产品范围、统计口径、实测/预测/估计属性、转换计算。实测还需适用的硬件/版本/模式、测试条件；销量与出货量、单季度与累计、均值与峰值不得混用。

用户数据先保留原值，未核验标明；来源不足时B先说明可替换版式与数据结构；C可做显式空数据骨架，但不能编造正式数字填满图表。用户允许演示数据时整图明确“演示数据”，不要只藏在代码注释。

20%→30% 是增加 **10 个百分点**，相对增长 **50%**；“增长了10%”不能替代前者。变化率以正确基期计算，基期为零时不输出无穷增长作为常规结论。百分比、倍率、百分点在标签、代码和口播中保持一致。

### 3.2 图表选择与防误导

| 信息关系 | 优先图形 | 关键限制 |
|---|---|---|
| 同口径分类比较 | 横向/纵向柱状、点图 | 柱长从零基线；不同单位分开 |
| 随时间变化 | 折线、必要时面积图 | 时间间隔按实际比例；缺失值不当零 |
| 总量组成/份额 | 少类别饼/环图、100%堆叠条 | 分母统一；缺项不能悄悄归一化 |
| 前后差异 | 配对条、斜率图、哑铃图 | 保留共同基准和前后对应 |
| 排序/排名 | 条形排名、明确排序的表 | 排序变化可追踪，别让动画藏掉实体 |
| 机制/流程 | 节点路径、分层结构图 | 箭头有明确含义，不冒充统计关联 |
| 时间事件 | 时间线 | 时间位置准确，若示意不等距须说明 |

饼图总和核对到合理舍入误差，缺“其他”项只有在分母与余量确实已知时才补；不得填造类别。折线非零轴确有助于看变化时显著标范围，避免夸大且有对照。双轴、截断轴、面积/体积编码慎用并清楚标识；装饰性 3D 不得改变数据长度或遮挡比较。

实测与预测用明确不同线型/区域和标签区分，不能只靠细微颜色。误差区间有数据才画。动画中的数字滚动与形状长度共享同一数据/插值，最终停留值必须等于原始数据；颜色图例、单位、来源和关键限定在成品中可读。

### 3.3 dataConfig

所有数据、来源和口径集中存放，计算值从原值推导，不在图层中多处硬编码。下列为结构示意，空值代表待补，不是生产数据：

```js
const dataConfig = {
  title: "待填标题",
  unit: "%",
  scope: { region: null, metric: null, period: null },
  status: "pending", // verified / user-unverified / demo / pending
  sources: [], // { id, title, url, publisher, publishedAt, accessedAt }
  series: [],  // { id, label, points:[{ x, y, kind, sourceId }] }
  notes: [],
  precision: 1,
  missingValuePolicy: "gap"
};
```

图表类型、颜色、字体和坐标范围另放 visualConfig；时间与缓动放 timelineConfig；画幅与布局放 layoutConfig。事实备注不因关闭装饰而消失。导出/保存必须连数据来源和编辑状态一起保留。

## 4. 可编辑工程底线

最终成品不能只是一次性播放网页。优先复用已有差点动效 Mini 母版；新项目也必须能改文字/数值/颜色/布局/节奏并保存。复杂编辑器功能按工程用途实现，但下列核心能力不能省成截图或仅配置源码。

### 4.1 画布、图层、控制区

播放区与控件区分离；默认 16:9 与 1183×1080 两套布局，核心安全框可开关，控制区不能进入 clean capture。窄版按【差点后期】重排，切画幅不丢数据与关键帧。

图层有稳定 ID；至少可控制实际存在图层的显示、位置、缩放、旋转、透明度、层级和合理轴心。数据/图形/标注/装饰/控件分层；删装饰不引发布局跳动。需要遮罩、扫描、玻璃、辉光等才加对应图层和控制，不预埋满屏无用效果。

中文面板按项目设置、内容、视觉、图层、时间轴、保存输出分组。数值有可输入框与合理范围，滑块不能成为唯一精确入口。现有工程的关键帧编辑、图层管理、导入导出等功能不得在美化时删掉。

### 4.2 时间轴与状态

统一时间源 t；播放、暂停、跳转、拖动和导出都从同一状态计算画面。不要多套计时器各自前进。关键帧至少支持当前需要动画的属性、时间和值；数值按指定缓动插值，布尔/字符串按保持或切换处理，不尝试把所有类型都做线性插值。

duration、fps、起止、循环、标记、关键帧集中配置。拖回同一帧应得到相同画面；随机纹理/粒子需要固定种子并能按 t 重建。默认预览帧率可沿用项目或设 30 fps，最终按用户时间线；风格里的低帧跳切是动作采样手法，不强迫把整个交付视频改成低帧率。

镜头节奏一般为“进入→变化→读取→退出”，阶段长度服从口播；数字到终值后留停顿，不一边挪坐标轴一边闪光一边推镜。音效只建议或加入关键进入/锁定/转折点，不能每个图层都有重音；实际加入声音必须有可用资产和来源。

### 4.3 保存与复用

单文件 HTML 优先提供“保存当前工程”：导出包含现有配置、图层、关键帧和必要资产引用的可重开 HTML，或随依赖一起打包；不能只写 localStorage。JSON 可作备份/导入，但不能在用户需要可直接打开工程时成为唯一成果。

多文件工程提供明确入口、依赖锁定和完整状态文件；AE 保存用户可编辑图层和控件；Remotion 保留 compositions、props/config 和源资产。支持撤销/重做有意义的编辑；保存后重开应恢复实际状态，而非回到默认 demo。

资产、字体和依赖若需联网，交付时说明并提供可行本地化/替代；不要宣称未实现的离线可用。避免用无期限临时 URL 作为生产唯一依赖。只有真实能工作的功能才能在面板显示为可用。

### 4.4 手机与预览

画布完整适配视口，不被固定宽高裁掉；手机用可见播放、暂停、拖动和保存按钮，不只依赖快捷键或 hover。触控拖动不误触页面滚动，参数面板可折叠；预览降采样可选，但不能更改导出尺寸。高开销光效、粒子、折射按需开，默认保证预览流畅和文字可读。

## 5. 材质、主题与动效约束

常用信息模板支持黑/白双主题，颜色集中配置并保证对比；用户指定深色叙事风时不强行反色破坏风格。000 的内部渐变光、卡片后柔辉光、轻折射/色散是可调独立层，不覆盖文字与真实数据。

优先做形状比例、排版与节奏，再增加真实有用的材质。文字边缘清楚，玻璃有限模糊与透明，色散只轻触边缘。背景网格、噪点、速度线和粒子只有表达主题或构成层次时添加，不默认全开。

伪三维可用统一透视、侧面与投影表达空间，不用巨厚柱体歪曲数值。真正三维模型、镜头和光照要有意义；前景文字尽量保持独立可编辑，必要时使用真实空间投影但保证可读。

## 6. AE 与输出适配

AE 界面、按钮、注释说明面向用户用中文。脚本访问属性与效果优先用稳定 matchName，表达式使用实际可用的表达式 API/稳定图层标识，避免依赖中文/英文界面显示名而报错。创建空对象、相机、灯光和效果后再绑定引用，防止缺失对象；可重复运行时避免名称碰撞和重复创建。

没有目标版本 AE 实机不能声称“已在中文 AE 26 测试通过”；区分语法/静态检查与宿主实测。必须插件依赖写清名称、版本要求和无插件替代，不能默认用户装了付费插件。

正式视频优先确定性逐帧渲染，预览可实时录制。确认实际容器、编码、宽高、帧率、透明能力；WebM 不能改后缀伪装 MP4。浏览器截图/录制不一定完整捕获 DOM、字体、WebGL、混合模式与跨域资源，须对最终导出核验，不承诺万能“一键导出”。只导出播放区，去掉控件和安全框；必要来源、单位与说明属于画面内容应保留。

## 7. 验收与交付

有运行环境就实际打开：检查初始帧、信息变化峰值、末帧；拖回同一时间是否一致；改一次数据/文字/样式；保存重开是否保留；切两种布局；手机可见控件与画布完整性；检查导出和预览一致。只测本次用到的核心路径，不为了简单修改重建测试系统。

交付工程文件/入口、预览或实际导出、两三句使用说明、数据来源及未测事项。修改已有工程时说明改了什么并保留原核心功能。能力不足则交可运行源文件和明确验证范围；没有实测结果就不写“全部正常”。最后按【差点质检】处理剩余问题。
