# 【差点素材】

- **负责什么**：真实视频/图片候选、事实信源、产品参考、真实 Logo、App 和 UI；提供可剪辑与可核验的来源。
- **何时调用**：宣传片、发布会、工厂、人物、真实事件、产品外观、参数依据、操作演示；生成或合成前需准确参考。
- **何时不要调用**：纯概念画面不必强找无关实拍；独立生成资产交元素，完整 AI 镜头交片段；不能用搜图代替图表数据核验。
- **常见触发词**：真实素材、宣传片、视频素材、产线、展台、发布会、官方图、Logo、App、UI、信源、出处。
- **输入**：文案片段、对象/型号/时间/地点、要看到的动作或角度、期望画质、已知参考、人工限制。
- **输出**：分别列出的事实证据与画面候选、真实链接、查看范围、可用内容、剪辑方式、身份/授权等风险状态。

## 1. 候选最大化，风险后置

先按内容相关性扩大有效候选，不因水印、Logo、字幕、博主出镜、转载或授权未知提前清空结果。先保留、去重、排序，再标注风险和处理建议。最大化指有效覆盖，不是反复堆同一视频的搬运链接。

把“是否值得看”与“能否直接用”分开：官方也不自动等于可商用；搬运也不自动等于没有参考价值。存在访问限制或版权争议时正常标注，不能承诺去水印后就合规，也不绕过付费或访问控制。

普通 B 段先找一个推荐和一个有差异的替补；关键 A/S 段通常给二到四个不同角度/动作的有效候选。数量是节省筛选的起点，不是上限；用户明确说“多找、尽量全、这批不够”就继续扩展渠道和关键词。

## 2. 把需求拆成画面项与证据项

画面项写成可观察动作：例如“厂房外景，建筑上能认出公司 Logo”“晶圆产线机械臂运送载具”“手机展开后真实桌面图标变化”。不要只搜“大厂”“AI 科技感”。

证据项是要核实的主张：例如“某公司已发布某技术”“某型号 CPU 架构”“统计口径下市占率”。每条对应具体来源内容，不能拿一条宣传片标题给整段技术结论背书。

| 类型 | 至少保留 | 不可混淆 |
|---|---|---|
| 事实信源 | 主张、支持内容、发布者/日期、链接、核验程度、限定条件 | 不保证有适合剪辑的画面 |
| 画面素材候选 | 链接、实际看到什么、对象身份、查看范围、画质/水印等情况 | 不自动证明文案中的事实 |
| 产品/品牌参考 | 型号版本、角度、配色、来源与识别特征 | AI 补出的角度仍是合成推断 |

参数、型号和时间遇到新信息应检索核实。用户给的内容暂记“用户提供，待核验”，不默认写入已证实栏。发现冲突直接指出哪一项，保留来源差异，不默默挑一个顺眼的数字。

## 3. 搜索渠道与策略

| 需求 | 优先渠道与检索顺序 |
|---|---|
| 国产产品宣传片 | B站品牌官方账号/搜索 → 官方发布渠道 → 高质量搬运或合集 → 商城详情视频 |
| 海外产品宣传片 | YouTube 官方 → 品牌官网/媒体资料页 → B站搬运 → 经销商与评测 |
| 干净产品图 | 官网购买/详情页 → 电商详情 → Google Shopping 快速比角度 → 图片搜索/可靠媒体图库 |
| 厂房、产线、展台 | 公司宣传片、官方活动、展会主办方、媒体探访；加入地名/年份/展会名/建筑 Logo 等画面词 |
| 历史人物或事件 | 原始发布机构、当时报道、档案机构；日期与地点需对应，不以现代再现顶替 |
| Logo/App/UI | 官方品牌资源、官网/官方商店和实际截图；Simple Icons 等成熟资源作可核对补充 |

每个方向组合中文和英文：`对象 + 动作/场景 + 媒介词`。例如`品牌 型号 宣传片 / official launch film`、`公司 工厂 航拍 / factory aerial`、`芯片 stacked memory animation / architecture animation`。结果不佳时改动场景词、别名、年份或渠道；不是同义形容词越加越长。

工作经验保留入口：[B站手机宣传片合集](https://space.bilibili.com/488124529/lists/6783395?type=season)可扩展候选；Google Shopping 适合快速比外观角度，再回商品源页；[Wilson Communications](https://www.wilsoncomm.com.hk/)可补查干净产品图。入口是检索线索，不保证一直可访问或必有指定型号。

官网没有下载按钮时，使用当前允许的页面/文件工具查实际公开资源。不得凭规律拼造视频地址。只有实际下载并验证过的文件才称“已下载”。访问失败换可用渠道；不要以浏览器或其他工具绕过已有连接器的明确限制。

## 4. 搜到后必须核对

尽量打开原页面确认：真实发布者、标题、日期、型号/配色、内容和文件可用性。搜图缩略图只供初筛，最终回来源页；“看起来像”不等于同型号。

视频能观看时确认实际画面；能获取文件时可抽帧、读时长并定位可剪区间。仅看标题/简介，标“未逐帧查看”；只看了片段，标具体范围。没有观看依据就不给精确入出点，改成“候选段落，需定位”。不能将搜索摘要中的时长或章节猜成真实剪辑点。

去重按原始视频或实际内容去重；一条高清源加一条可访问备份足够，不把十个搬运算十个独立候选。高相关性优先于形式干净，确有实用差异再保留多版本。

## 5. 产品真实性与 AI 补角度

保留影响身份的轮廓、摄像头/接口布局、按钮、比例、配色、Logo 与型号。点名真实产品但外观未确认时，继续检索该品牌/型号的待核验候选；不能擅自改成无品牌通用手机。

只有真实资料不足、任务允许合成时，才把可靠参考交【差点元素】或【差点片段】生成角度。明确“合成示意、未验证不可见面”；前后视图尽量共同约束，不能发明接口、镜头数量和未公布细节。真实 UI 操作与品牌标识优先保留原始素材/单独图层，不让模型重新拼字。

【只找真实素材】范围内绝不启用生成补缺。已有厂商 CGI 宣传片可以作为真实来源素材候选，但须标“厂商 CGI 演示，非实拍”，不能把来源真实误写成场景实拍。

## 6. 风险标记与后期建议

风险采用短标签按需列出：`官方/媒体/转载`、`身份已核/身份待核`、`授权已确认/授权未知`、`水印/字幕/博主出镜`、`画质不足`、`厂商CGI/AI合成/实拍`、`仅页面可访问/已下载`。授权已确认必须有依据。

剪辑建议要具体：适合哪句、展示什么、是否需要裁切/遮罩/配字/局部放大、横版到窄版是否会切掉 Logo。不要让补画面暗示虚假的厂商归属、技术状态、人物行为或时间地点。

## 7. 交付模板与停止条件

简短素材任务直接给候选：

| 推荐 | 链接与发布者 | 可用画面/对应原文 | 查看程度与入出点 | 风险及使用建议 |
|---|---|---|---|---|
| 1 | 实际来源页或已验证文件 | 具体内容 | 实际观看范围；未知则待定位 | 只写相关风险 |

需要事实核验时另列：`主张｜来源链接/日期｜支持程度｜限制或冲突`。不能把两表合成含糊的“参考资料”。

候选足以覆盖当前镜头就交付并进入制作。找不到时说明已经检索的核心渠道、具体缺口和最接近的替代；在用户允许范围内改镜头机制或真实对象视角，不能悄悄换成不相关产品，更不能假造来源。搜索词只在工具确实不能检索时作为降级交付，不代替本来能执行的搜索。
