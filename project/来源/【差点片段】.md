# 【差点片段】

- **负责什么**：完整镜头级 AI 图像、视觉锚点、AI 视频、CGI、概念 B-roll、历史/未来重建及粗动效最终渲染。
- **何时调用**：需要完整环境与动作；不可拍/难获取的概念；芯片内部 CGI；草稿视频升级为最终视觉；已有参考需重构完整场景。
- **何时不要调用**：独立 PNG 交【差点元素】；真实现场/产品证据交【差点素材】；精确数据与排版变化优先【差点动效】；真实素材限定范围内不生成补缺。
- **常见触发词**：片段、CGI、锚点、图生视频、生图、生视频、概念 B-roll、历史重建、粗动效、最终渲染、改材质光线。
- **输入**：文案/镜头描述、图片或粗视频、必要真实参考、风格编号、动作、时长/节奏与保留限制。
- **输出**：已生成锚点图、简短视频 Prompt、必要的镜头/连续性说明，以及实际生成的视频或明确标记的未生成状态。

## 1. 先确定镜头任务

先理解文案关系，交【差点视觉】定主视觉；一个镜头一个主视觉、一个主动作。AI 不擅长保持的精确 UI、数字、图表和品牌文字转为后期叠加，主体镜头负责形体、空间、材质和叙事。

真实产品外观和技术结构需要【差点素材】提供依据。芯片内部空间没有公开布局时，只能做抽象层级/数据路径的“结构示意”，不能编造某型号的真实晶体管布局。历史/未来、商业隐喻和匿名剪影均明确为概念或重建，不当作事件现场证据。

画幅和真实性遵循【差点后期】。当用户只要提示词，就直接交精炼提示词；未要求制作整段时不扩大任务。整篇文案已授权制作，则继续实际可做的图像/视频步骤。

## 2. 默认流水线：先锚点帧，再视频

1. 选一条清晰机制，确定主体身份、场景、构图、光源、材质和动作终点。
2. 读取对应风格卡，写一段可直接生图的静帧提示词，实际生成一张视觉锚点。
3. 检查主体、结构、主次、材质、光线；锚点不成立先改锚点，不指望视频自动变好。用户已有批准锚点就复用。
4. 用锚点约束外观，用文字/动作参考约束运动；编写短视频 Prompt，有工具则继续生成并检查。
5. 视频确认对象身份、数量、运动方向、镜头连续性和文字稳定后交付。模型输出若有误，局部或分段修正。

简单动作通常一张锚点够用；明确的前后状态可用首尾两帧；复杂转折确需多镜头才增加关键帧。不要默认四宫格、四关键帧、三段拼接，也不默认每帧都独立随机生成。

没有显式“先确认再做”，锚点通过自检后继续。用户要求确认方向，交锚点停在确认点；不将这条等待强加给所有任务。

## 3. 静帧设计

静帧提示词保留真正影响画面的内容：主体与功能关系、构图和空间、机位、材质与光源、风格、真实识别约束、后期文字安排、少数禁项。优先具体造型和光照描述，不靠“超高级、8K、获奖、电影感”堆叠。

指定“人工 CGI”默认使用 016：像专业三维设计师重新建模和布光的成品，不等于照片感重绘。用户要求重构时，参考图只锁主题、必要身份与信息关系，允许重做构图、机位、材质和布光；用户要求保留构图时才锁这些项。

字体需保持原图时保留原始文本层/独立合成，AI 底图不重写最终文字。必须准确的编号、Logo、单位和公式同理。不能用“保证文字完全一致”掩盖模型能力限制。

## 4. 粗动效 → 最终渲染模式

收到粗视频＋文案，直接进入此模式，不再让用户重新描述所有可观察信息。

### 4.1 实际读取视频

使用当前可用视频读取能力；可访问本地文件时，必要时读时长、帧率并在起点、关键动作、转折和结尾抽帧。实际看过再分析。若只能读部分，说明范围；文件无法解码才请求重传/关键帧，不根据文件名编动作。

记录五项：构图和相对位置、占位元素对应什么、元素运动路径、摄影机运动、节奏/停顿。区分对象移动与摄影机造成的视差，区分真实时间信息与主观估时。

### 4.2 分清锁定项与重设计项

| 从粗视频继承 | 根据文案与风格重新设计 |
|---|---|
| 主体相对位置、出入方向、遮挡关系 | 最终物体造型、合理细节与占位物身份 |
| 运动路径、先后顺序、节奏、停顿 | 材质、表面、布光、阴影、反射、光效 |
| 明确的机位与摄影机路径 | 背景/场景与气氛，前提是不破坏所需运动空间 |
| 用户明确要保留的图形或排版 | 除指定保留外，粗线框、纯色方块与默认字样不作成品外观 |

例如文案讲“算力与存储贴近”，草稿两个方块互相靠近：方块是运动占位，最终可重建为具有明确材质和层级的两组芯片模块，不只给原方块加金属滤镜。必须先确定隐喻不暗示未经核实的具体封装技术。

不要同时写“严格保持原视频所有视觉不变”和“彻底重做材质场景”。约束必须明确分工：**动作视频负责运动与时间，渲染锚点负责最终外观，文案负责内容含义。**

### 4.3 选一帧并渲染

选主体完整、关键关系最清楚、能代表最终视觉且没有过渡模糊的一帧；提供实际时间位置和选择理由。不是机械取中间帧，也不总取第一帧。

以该帧为布局参考，按文案映射占位物，写静帧 Prompt 并实际生成最终渲染参考图。检查是否真的完成造型、材质、光线、场景重设计；如果仍是“粗视频同样的方块，只变亮”，重做锚点，不直接推进视频。

### 4.4 默认交付四项

简短运动分析；一段短视频 Prompt；锚点时间与静帧 Prompt；一张实际渲染静帧。用户还要求视频且工具可用时继续生成；只有图片工具时明确视频尚未生成，不能暗示完成重渲染。

## 5. 短视频 Prompt 模板

默认三到五句，用具体动作，少用形容词。已有锚点不重复长篇材质清单；负面约束只保留本镜头最容易失败的三到五项。

**一般镜头：**

> 以所附锚点为最终外观：[主体]在[场景]中完成[唯一主动作及终点]。镜头[固定/明确的一种运动]，节奏[进入—变化—停留]。保持主体几何、数量、材质和光源连续，必要文字由后期叠加。

**粗动效重渲染：**

> 用草稿视频约束构图、运动路径、镜头和节奏，用渲染锚点约束最终外观。将草稿中的[占位元素]重建为[与文案一致的具体对象]，采用[风格核心材质与光照]。保持[关键动作/关系]，重新完成场景与表面细节，不保留粗糙占位外观；主体形状和数量连续稳定。

有实际时间依据时填具体起止与停留，无依据就写相对阶段。上传“动作参考视频”和“外观参考图”的槽位名称以当前模型实际界面为准；不编造平台支持的参数，也不保证所有模型都能分离运动与外观。

## 6. 连续性与失败降级

检查开始、转折、动作终点和尾帧；关键运动必要时多抽帧。关注：物体数量不变、轮廓不熔化、接口不漂移、遮挡合逻辑、材质不跳变、光源不闪、相机不无故转向。反射随相机合理变化，不能为了“稳定”冻结全部高光。

视频没有明显重渲染变化：先查参考分工是否冲突、最终锚点是否足够不同、工具是否真支持此参考方式；删掉保留旧外观的句子，明确占位到成品的映射。模型持续不听时换为锚点图生视频、按动作拆段或真实二维/三维工程，不无限加长 Prompt。

一轮针对主要问题修正后仍不行，再做一次有明确新方法的尝试；没有新变量就降级。复杂 CGI→稳定静帧＋轻运动→真实素材＋标注→简单二维动效→成熟模板，依内容和现成资产选最短可用路径。不得用强运镜掩盖坏几何或不准确内容。

## 7. 交付状态

每镜头交：镜头号、对应原文、锚点/视频文件、必要 Prompt、时长依据、画幅重排、概念/真实标识。只有静帧就写“锚点已生成；视频未生成”，只有 Prompt 就写“制作指令已准备，画面待生成”。所有状态遵循【差点后期】，最终质检用【差点质检】。
