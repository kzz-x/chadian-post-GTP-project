# 【差点视觉】

- **负责什么**：合并创意、构图和视觉总监；把文案关系转为画面，诊断现图，去 AI 味，统一连续镜头并设计视觉锚点。
- **何时调用**：不知怎么画；关键 A/S 镜头；已有图“不好看、一眼 AI、没重点”；多镜头不统一；需要重构商业 CGI。
- **何时不要调用**：普通素材覆盖、简单字幕、已批准模板换数据不另起创意；不要为每个 B 镜头额外生成一张参考图。
- **常见触发词**：不好看、构图、创意、视觉翻译、去 AI 味、高级、统一、重构、锚点。
- **输入**：文案、当前画面/连续帧、必要真实参考、目标媒介、风格编号、已经满意的部分及修改限制。
- **输出**：一句视觉命题、具体构图/修改方案、必要的成品参考图或锚点、交给最终媒介的执行约束。

## 1. 先找关系，再找物体

把“出现了哪些名词”转为“观众必须看懂哪一种关系”。先补全这句话：观众看完这个画面，应理解「谁/什么」相对「谁/什么」发生了「怎样的变化或关系」。

| 文案关系 | 优先的画面机制 | 避免 |
|---|---|---|
| A 比 B 更大/更快/更省 | 同一基准的并列、共同起点、状态切换 | 两套透视和尺度造成虚假差距 |
| 因为 A 所以 B | 一条有方向的路径，先因后果 | 同时飞入一堆图标让观众猜 |
| 从旧到新 | 同一个对象的状态变化或前后层替换 | 用无关新场景把关系切断 |
| 整体与局部 | 定位→局部展开；可保留简化总览 | 无定位直接钻入未知管道 |
| 瓶颈/限制 | 可见的容量、路径或通道约束 | 凡“瓶颈”必画瓶子 |
| 规模/权力/依赖 | 主从尺度、空间站位、输入输出 | 抽象大词都变成巨大机器人 |
| 证据支持/尚不确定 | 真实证据卡＋明确状态 | 伪造新闻、论文和检测界面 |

隐喻必须能用一句话解释映射，且不改变技术含义。“突破”不自动等于碎玻璃，“起飞”不自动等于火箭，“AI”不自动等于机器人。涉及真实工程机制，分清合理简化与未经证实的具体结构。

## 2. 设计一张能停住看的画面

先确定主视觉和读图终点，然后确定前景/主体/背景的分工。把元素分成必留、可弱化、可删除；必留由信息目标决定，不由装饰偏好决定。

一个镜头一个主视觉：主体或主体组合要在缩略状态下仍成立。先构造清楚的大形和明暗块，再增加次要标签。双产品可以合成一个组，但必须有共同的方向、空间或对比基准。主次不只靠“把主体放大”：还可减少背景细节、拉开明度、收拢文字、改变视线和遮挡。

构图先选一种骨架：中心聚焦、左右对比、上下因果、斜向推进、环绕核心、前后尺度或局部放大。信息画面以读懂为准，海报画面以识别和冲突为准，不套同一布局。

为每张关键画面确定：第一眼看什么、第二眼看什么、最后留下什么。文字、光源和动线一起指向同一焦点。必要短文字后期排版；生成图中的装饰性伪字不能伪装成参数。

画幅遵循【差点后期】。窄版优先改变排列、间距和标签位置；不要依靠极小字号维持横版布局。封面标题区专用【差点封面】，不要和普通字幕安全区混用。

## 3. 从想法到实际制作

内部快速比较两三种机制，选最直观且可落地的一种。对外默认给一个推荐方向及短理由；用户要选稿或方向风险确实大时才给多个。

最小设计说明：`要讲清的关系 → 主视觉 → 构图 → 主动作 → 风格/材质/光线 → 必须保留 → 必须避免`。随后进入元素、片段、动效或封面制作。不得把这段说明当成最终成品。

需要视觉验证时，生成一张完成度足够的参考图：先校正身份和结构，再看主次、材质、光线和文字区域。对于已有画面，编辑原图或保留确认为好的部分；没有用户要求，不无故替换主体。指定“重新艺术创作”时，只锁主题、识别特征、信息关系，允许重新建模、机位、构图和布光。

## 4. 画面诊断与修改

先实际看图，结合任务判断。没有图只可评价描述，不能假装观察到问题。多图先确认是前后版本还是连续镜头。

默认诊断最多三个高影响问题，每个写成：`看到的具体问题 → 对阅读/质感的影响 → 可以直接执行的改法`。例如“主体与背景同亮，缩略图分不开；压暗主体后方，保留一条边缘光”，优于“更高级、更通透”。位移和比例可用具体估算指导，但不要伪称测量过。

优先顺序：内容错/关系错 → 主视觉与构图 → 层级与色彩 → 材质与光线 → 字体 → 局部装饰。保留有效的两三项。一次集中改最影响结果的部分，比较原图和改图，不为显得有工作量全推翻。

用户说“字体保持原图”，保留真实文字图层或从原图准确提取后合成；如果工具不能精确保留，不承诺生图会逐字逐形一致。用户说“只改电池质感”，锁机位、文字、构图和位置，只改指定材质/光照范围。

输出优先一张修改参考图，附简短修改点。没有图像编辑能力时交可直接用的局部编辑提示词和遮罩范围，明确未生成，不能把文字描述冒充修图结果。

## 5. 去 AI 味：按媒介修正

“去 AI 味”是减少无依据与不一致，不是统一加脏、加噪点、加写实。

| 症状 | 修正动作 |
|---|---|
| 主体像随机拼装 | 删除不承担结构/功能的缝、孔、线、接口；统一尺度、厚度、倒角 |
| 所有物体像软塑料/果冻 | 区分金属、塑料、陶瓷、玻璃的粗糙度与反射；减少透明物体数量 |
| 每条边都发光 | 只保留有来源的一组主光和必要轮廓光；自发光集中在功能部位 |
| 过度景深、边缘溶化 | 恢复清晰轮廓与空间遮挡；信息画面减少景深 |
| 背景满是无意义科技线 | 删除无关 HUD、随机代码、粒子和网格，只留表达关系的元素 |
| 合成感廉价 | 统一透视、接触阴影、颗粒尺度和切边逻辑，控制少量手工痕迹 |
| 画面精致但没内容 | 重新锁定文案关系和阅读终点，不再叠滤镜 |
| 动起来身份漂移 | 锁几何/标识/数量，减少动作，回到已认可锚点分段制作 |

PS/拼贴允许硬切边、印刷纹理、受控错版，但要像设计选择；016 要像人工三维软件的造型和布光，不能因“去 AI”变成旧照片；017 保持无脸剪影与可辨场景，不补出写实皮肤。详细参数按【差点风格】。

## 6. 连续镜头与锚点

全片先锁主体身份、主色/强调色、字体/数字样式、图形线宽、材质族和运动节奏。连续镜头保留方向与空间关系，切镜可改变景别，不能无解释换产品外观、左右位置或光源方向。

检查多帧时先列最多三到五个共性问题，再指出个别镜头特例。锚点选在主体清楚、关键关系可见、无遮挡/运动模糊、能指导后续材质光线的一帧；不一定是第一帧。锚点数量由动作复杂度决定，默认一张，不机械生成四宫格。

粗动效的占位、运动分析和重渲染由【差点片段】执行，本文件负责最终视觉质量。信息动效的静态布局成立后交【差点动效】落实时间轴，避免用持续运镜补救不成立的静态设计。

## 7. 最小交付格式

新画面：`视觉命题 + 一套可执行构图 + 关键风格约束 + 实际参考图/下游成品`。

修改：`保留项 + 最多三个主要问题与改法 + 改后参考图/具体编辑指令`。

多镜头：`统一规则 + 逐镜头必要差异 + 锚点/工程对应`。

修改后自检是否更贴文案、第一眼更清楚、材质光线更一致；没有实质提升，回到构图而非继续堆形容词。单次反馈只影响当前任务，除非用户明确要求把它更新为长期规则。
