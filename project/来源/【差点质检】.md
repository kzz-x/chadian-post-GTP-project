# 【差点质检】

- **负责什么**：按媒介检查可用性与主要质量风险，修复最影响结果的问题，必要时降低制作复杂度。
- **何时调用**：交付前、用户不满意后、改稿后、导出/保存后；关键锚点进入视频前。
- **何时不要调用**：不为简单可逆小修改建立庞大测试系统；不把质检当反复暂停等确认的理由；不检查本次不存在的媒介。
- **常见触发词**：检查、验收、不好看、一眼 AI、错数据、画面裁掉、不能保存、打不开、赶工。
- **输入**：原文与限制、实际成品/工程、来源、目标画幅、已批准参考、实际测试环境。
- **输出**：已修复的成品；仅与交付有关的通过项、未完成项和必要限制；需要时明确降级方案。

## 1. 先检查三件事

**是否讲对、是否一眼看懂、是否真能用。** 先看实际文件或运行结果，不根据 Prompt 自评成品。未生成、未打开、未看过的内容不能判“通过”。

从内容→构图→工程的顺序，先修最多三个主要问题。只有剩余问题真实影响目标时才继续迭代，不能无限优化装饰。

## 2. 通用画面检查

| 检查 | 通过标准 | 失败时先做什么 |
|---|---|---|
| 内容/关系 | 对应原文，否定、限定、对象、时间不丢；隐喻不改变事实 | 回到视觉命题，改错对象/关系 |
| 主视觉 | 缩略图有明确焦点；一个镜头一个主视觉 | 合并主体组，减少背景竞争 |
| 构图/层级 | 阅读顺序清楚，文字不盖核心，遮挡有意义 | 重排主次与间距，别先加滤镜 |
| 色彩/字体 | 主辅色有分工，文字可读，字体风格与字形正确 | 减强调色，统一字重与数字样式 |
| 材质/光线 | 表面差异明确，光源和阴影合理，轮廓清楚 | 减无来源发光，修接触与倒角 |
| AI 味 | 无随机机构、伪参数、熔化边、过度果冻/塑料 | 删除无意义细节，按媒介修真实逻辑 |
| 动效 | 一个主动作，能读到终点；运镜有目的 | 固定镜头，减少并行动作，增加读取停留 |
| 真实性 | 事实/用户待核/概念/预测区分，真实身份有依据 | 核验或显著标示意，不用生成补证据 |

## 3. 画幅检查

普通画面默认 16:9；检查 1183×1080 中央裁切预览中关键主体、数字和短字能否保留。横向关系不适合裁切，就检查独立重排方案，而非一律缩成小字。用户要求实际双版时核对两份真实输出尺寸与可读性。

封面分别检查 16:9 与 3:4：同卖点与主体，独立构图；按用户示意横版中下部、竖版下半部居中的标题兼容区，底部有余量，背景完整且低冲突；无最终大标题误烘焙，关键识别点不被标题压住。不能把机械裁切当完成竖版。

## 4. 按媒介增补

- **素材**：链接真实可访问程度写清；标题/摘要/实际观看分开；画面候选与事实信源分开；风险标签不遗漏；未看视频不写精确入出点。
- **元素**：单体完整、alpha 真实、边缘无污染、格间不串影、数量视角正确；组图与独立文件状态分开，实际单格像素够用。
- **片段**：锚点画面先成立；视频检查起点/转折/终点与必要中间帧，身份、数量、运动、光源连续；粗视频最终外观有实质升级，Prompt 没有互相打架的保留要求。
- **数据图表**：来源、单位、口径、时间范围、实测/预测清楚；百分比与百分点正确；数据和图形一致；轴/面积/透视不误导；缺失值未当零，未擅自归一化；dataConfig 可改。
- **工程**：打开与主要播放路径可用；改值能生效；seek 可重复；保存重开状态不丢；图层与面板可操作；手机无只靠 hover/键盘的关键功能；实际导出无控件、缺字体、错编码或错画幅。
- **封面**：缩略图看清主主体与冲突，标题测试可读；真实品牌无变形；横竖两版各有文件或明确未完成状态。

## 5. 降级：保结果，降复杂度

复杂 CGI → 稳定静帧＋轻运动 → 真实素材＋标注 → 简单二维动效 → 成熟模板。按现有资产和文案选最快可用路线，不要求每一级都尝试。用户【只找真实素材】时只能在真实候选和真实素材包装内降级。

可减少景深、粒子、透明层、运镜、转场、镜头数量和定制程度；不可降低事实准确性、图表比例、文字可读性、主体身份与已承诺的编辑/保存能力。复杂效果删去后画面更清楚就是有效优化。

## 6. 检查报告保持轻量

没有问题时不附全套检查清单，直接交文件与简短使用说明。有实质限制则写清：什么已完成、什么未测试/受限、影响什么、现有替代。模拟规则检查不等于真实 Project 运行测试；代码静态检查不等于 AE 宿主实测；Prompt 检查不等于成品画面合格。

已授权的修复直接做；只有缺真实输入或用户明确要求确认才提问。交付最终版本，避免把十个中间失败稿留给用户重新筛选。
