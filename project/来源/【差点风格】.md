# 【差点风格】

- **负责什么**：000–017 正式风格卡的构图、色彩、材质、光线、排版、镜头、动态与 AI 约束；将风格变为可执行的视觉决定。
- **何时调用**：用户指定编号/参考；元素、片段、动效、封面需要统一外观；重构 CGI 或连续镜头需要稳定风格。
- **何时不要调用**：不以风格替代文案理解、事实核验和制作流程；不为每段文案换一张卡；不强迫真实实拍变成生成风格。
- **常见触发词**：风格：000/016/017、人工 CG、酸性、玻璃、纸面、剪影、复古、拼贴、统一视觉。
- **输入**：文案关系、媒介、参考、指定编号、已批准母版、画幅、动静态用途和真实性限制。
- **输出**：选定主风格及必要补充手法，落到当前主体的构图/材质/灯光/动作约束，交下游当前阶段使用，不能因调用风格而自动开始制作。


## 阶段与风格落实

按【差点后期】阶段控制。A作初选，B实际读对应卡并把风格转为当前主体的具体决定，C按已确认方案实现，D检查偏差；调用风格不触发生成。

B交`编号/卡名与已读章节｜为何适合当前关系｜构图/主辅色/材质/主光/图形/动作的具体选择｜本镜头不采用的风格特征｜参考与确认项`。下面卡片中的“大字、标签、编号”仅为风格手法，封面不生成最终大标题与杂乱文字的任务规则优先。允许少量准确相关小字，不能把风格里的标签全部照搬，也不能把无大标题变成全禁文字。

参考母版优先于泛泛形容词。选到正确编号不代表已经做到对应风格：还需在设计和成品上看见构图、材质、光照与层级的落实。各卡的专业内容保持独立，不用阶段规则替代其视觉细节。

## 调用规则与索引

先内容关系后风格。用户指定编号优先；没有指定时，常规硬件信息视觉可从 000 起选，说明类可选 002，真实材质/商业 CGI 选 016，场景关系叙事选 017。不得因“科技”二字默认蓝紫霓虹。已有批准母版优先复用。

一镜头一张主卡；必要时补一种明确手法，例如 017 的叙事舞台＋016 的建模/布光完成度，不能把两卡所有特征堆满。参数与色彩比例是视觉参考，不是每张图必须逐项凑齐的硬配额。字体举例需实际可用、中文字形完整且授权适用；精确标题/数据/Logo 另用可编辑图层。

## 000｜轻液态玻璃粗野酸性竞速机能 UI

- **适用**：硬件评测、消费电子参数、排行榜、数据图表、发布会信息视觉、VibeMotion 母版与科技封面。不是所有题材的强制皮肤。
- **核心视觉公式**：轻液态玻璃/毛玻璃的通透层次＋粗野压缩字的硬信息＋少量酸性警示色与竞速编号；“轻、薄、清楚”先于折射炫技。
- **构图**：一处产品/数字主焦点，非对称但对齐明确；卡片层次少而有关系，留出呼吸和稳定文字面。巨字、参数、细标签形成三级，玻璃不把画面切成等权的圆角卡片墙。
- **色彩**：白主题用冷白、雾灰、银白；黑主题用深炭黑、石墨黑。中性色为主，冷色信息、酸绿/黄绿等少量高亮作强调。可参考中性约70%、玻璃层约20%、冷色约8%、警示约2%的视觉分工，不机械测面积或同时用齐所有色。
- **材质**：薄半透明卡片，轻微毛玻璃模糊与可解释反射；边缘厚度克制，不做厚水晶、果冻或软胶。保留硬边/小圆角与清楚轮廓，卡片底与后方内容有真实层级。
- **光线**：白主题卡片内部有极淡、宽而柔的微软式渐变光流；黑主题卡片后可有大面积柔渐变辉光，亮度集中于结构分离，不给每条边加霓虹。高光随层面合理变化，文字层不被光影穿透。
- **排版 / 图形**：压缩黑体/粗黑体主标题，DIN 类窄体或等宽数字，中文选完整且清楚的黑体。机能标签、刻度、编号和短线只表达内容层级；无意义代码/伪参数不要上屏。准确字后排。
- **镜头**：信息画面默认正面固定；必要时轻微推进或层间视差，幅度不能改变读数与排列。产品可有独立三维角度，文字仍稳定。
- **动态**：系统启动/框架定位→卡片短促切入→标题硬切→数字滚动或线条生长后锁定→内部光与辉光低幅缓动。每阶段一个主动作，读取阶段安静；速度线/故障只点到为止。
- **禁忌**：默认蓝紫霓虹、厚透明水晶堆、全屏软圆角、强扭曲文字、全边描光、过量彩虹、手写/书法主字体、均匀粒子铺满、所有层不停漂浮。
- **AI 生成约束**：画面 Prompt 明确“薄而受控的玻璃、硬信息层级、低饱和底色、极少强调色”；不要同时要求高透明与大面积高密不透明发光。静帧锁卡片边界和主视觉，视频保持几何与文字位置。代码实现可用半透明层与 backdrop blur，轻扰动/边缘约1–2px低透明色散仅在必要时加入；这是效果参考，须按实际输出尺度调整，不能让滤镜扭曲数据。

## 001｜粗野未来拼贴

- **适用**：科技争议、硬件观点、行业趋势、参数冲突、强态度开场和封面。
- **核心视觉公式**：硬边网格＋产品/人物切片＋金属与像素反差＋少量强色冲击，像有意编辑的工业拼贴。
- **构图**：非对称分屏、错位但有基准的网格；一个主切片，材质区、标签区、强调区从属于它。裁切和遮挡要利落，避免碎片均匀散开。
- **色彩**：近黑、炭灰、冷黑蓝与银白主导，青或酸色作为约10%–20%的冲击参考；强调色少而集中。
- **材质**：金属、哑黑、像素/印刷面选两三类，硬质层面与清楚切边；细纹理不覆盖识别特征。
- **光线**：主主体硬朗主光和有限轮廓光；平面拼贴层用统一投影逻辑，不给每片独立光源。
- **排版 / 图形**：DIN/Bebas 类窄体、中文重黑体、等宽小标签；粗细对照、局部巨字、工业编号，信息必须有意义。
- **镜头**：以平面正视、产品局部和硬裁切为主；轻视差即可，不以环绕三维抹平拼贴感。
- **动态**：硬切、网格滑移、遮罩切片、短促吸附和到位停住；故障限定边缘或转场，主体读取期稳定。
- **禁忌**：软萌卡片、过多圆角、果冻弹性、所有材料同亮、满屏随机故障、没有语义的碎片堆积。
- **AI 生成约束**：保留抠图边界、网格与材质分区，不熔成写实场景；产品身份与文字独立核验。视频不能让切片随机增殖、Logo 变形。

## 002｜蓝白界面说明板

- **适用**：功能教程、软件机制、流程拆解、产品卖点、清爽数据说明。
- **核心视觉公式**：蓝白底＋少量说明卡＋一条清楚关系路径，像精心设计的产品说明界面。
- **构图**：主体/关键步骤明确，通常两到四个信息单元；统一对齐和边距，空白用于分组而不是空洞。
- **色彩**：白、冰蓝、浅灰主导，清晰的蓝色作主要强调，饱和蓝占比克制；警告色只在确有状态差异时出现。
- **材质**：薄磨砂、浅色塑料或轻纸面，轻层叠和细阴影；不要厚重透明水晶。
- **光线**：柔和均匀的屏幕/棚拍式亮度，文字与线条反差足够；弱接触阴影分层。
- **排版 / 图形**：Inter/思源黑体等清晰无衬线，等宽数字；短标签、箭头、步骤号统一，真 UI 用真实参考。
- **镜头**：正视固定；必要局部放大明确定位后返回，不加浅景深糊掉周边步骤。
- **动态**：卡片进入→路径生长/光标指向→状态切换→停留。缓动轻而准确，不让全部单元同时弹跳。
- **禁忌**：大范围故障、强酸色、密集 HUD、厚重金属、无意义镜头绕行、极细低对比小字。
- **AI 生成约束**：生成只负责可用底板/概念图形，精确步骤和文字后排；界面不得冒充某软件实际功能或真实操作记录。

## 003｜纸面档案蓝图

- **适用**：历史资料、证据链、故障复盘、技术拆解、事件时间线、图纸说明。
- **核心视觉公式**：纸面资料＋工程线稿/蓝图＋克制红笔批注，让观众跟着证据和关系阅读。
- **构图**：一份主资料或一张主图，周边证据从属；卡片、批注与连线形成可追踪路径，不做无中心资料墙。
- **色彩**：纸白/浅黄、灰蓝、黑色细线，少量红色用于圈定与连接；不强制全部泛黄成古董。
- **材质**：纸纤维、复印颗粒、轻胶带/折痕、图纸网格按需使用；真实截图清楚，纸张厚度和边缘统一。
- **光线**：俯拍/扫描式均匀光，轻纸面接触阴影；资料文字区避免强反光和深暗角。
- **排版 / 图形**：打字机/等宽小标签与清楚中文黑体，工程标线和红笔批注分工；证据内容必须真实可追溯。
- **镜头**：正俯视或轻倾角，定位式推进/平移，不用复杂景深和三维环绕。
- **动态**：纸卡进入→扫描揭示→红框锁定/连线→结论停留；先显示证据再显示推断。
- **禁忌**：伪造论文新闻、满纸乱码、过量污渍、霓虹玻璃、恐怖犯罪墙、每张纸都贴胶带。
- **AI 生成约束**：可生成空白档案底板与非事实性道具；真实文献/新闻需原图后合成。纸张不能融化，红线两端明确，不产生虚假证据印象。

## 004｜电影级插画海报

- **适用**：行业寓言、游戏/影视类比、概念开场与情绪封面；不适合承担精确产品外观证据。
- **核心视觉公式**：强轮廓主角＋前中后故事空间＋一套明确色彩叙事，形成一张可停留的插画海报。
- **构图**：中心/三角/斜向聚焦，主角轮廓一眼能认；前景引导、中景动作、背景交代环境，细节服从主冲突。
- **色彩**：一到两种主色加有限对照色，可用冷暖叙事但不默认全蓝橙；主体与背景明度分开。
- **材质**：受控笔触、插画质感、印刷颗粒；不要把插画、摄影、塑料三维随机混成一层。
- **光线**：戏剧主光、边缘光与有限气氛层，主要光区指向故事核心；暗部保留层次。
- **排版 / 图形**：可选电影感衬线/重黑体，与主题一致；最终标题后排，边缘小标签少用。
- **镜头**：英雄式中/广景，机位表达人物与环境关系；静帧成立后才轻微视差，少量推进。
- **动态**：海报分层、光影缓变、局部动作；一次只动主要关系，不让全场漂浮成幻灯片特效。
- **禁忌**：无主题电影烟雾、游戏广告式堆角色、过度锐化、人物/产品身份错误、标题占位挤走主视觉。
- **AI 生成约束**：人物肢体与物体数量明确；寓言/重建不能充当真实事件照片。连续帧保持角色造型、场景比例和插画笔触。

## 005｜消费电子信息场

- **适用**：手机、芯片、眼镜、接口、充电器、AI 硬件的产品展示与参数解释。
- **核心视觉公式**：准确产品英雄图＋功能定位＋外围克制参数场，产品始终是中心。
- **构图**：产品主体占据关键视觉，标签避开核心轮廓和识别部位；引线连接具体功能，参数成组而非环形围满。
- **色彩**：产品真实色优先，深青/蓝黑或干净中性色作环境；青蓝/绿少量提示功能，黄色只在需强调时用。
- **材质**：准确玻璃、金属、工程塑料与屏幕；电路/PCB 仅在与当前功能有关时作为次层。
- **光线**：有来源的棚拍产品光，轮廓与表面可读；屏幕/接口发光必须有功能解释。
- **排版 / 图形**：DIN 类数字、清楚无衬线与等宽标签；参数、单位、图标统一，真实 UI 和 Logo 用原资产。
- **镜头**：产品英雄角度、微距功能局部、有限视差；定位变焦前后有明确空间对应。
- **动态**：产品到位→扫描定位→参数显现→停留；数据流只用于真正需要说明的路径。
- **禁忌**：随意加接口、假 UI、随机电路背景、产品全透明、每个零件发光、信息压住品牌识别。
- **AI 生成约束**：具体型号先取可靠参考，锁轮廓/配色/结构；生成不可见面标推断。视频光照可连续变化，外观与标识不可漂移。

## 006｜高密度观点缩略图

- **适用**：观点、争议、辟谣、消费警示、行业吐槽和高识别封面。
- **核心视觉公式**：一个大主体/主体组＋单一观点冲突＋强弱分明的标题环境；密度来自信息组织，不是东西多。
- **构图**：大近景与受控切边，背景满版但层级更低；标题区域依【差点封面】的用户横竖示意，不能恢复旧固定下方比例。
- **色彩**：黑/深灰与强对照色，红、绿、黄中按主题选一两个强调；文字区要与标题方案形成清楚反差。
- **材质**：真实图/三维图的手工抠图合成，适量硬描边、投影、印刷纹理；主体各层统一颗粒与明暗。
- **光线**：主体亮暗块明确，局部冲突可用定向光，不用全屏泛光抹平硬合成感。
- **排版 / 图形**：Impact/Anton 类重窄体与中文重黑体；少行短标题，辅助标签极少，AI 底图不烘焙最终字。
- **镜头**：静态封面为主，缩到约10%仍可认主体；片内化时使用有限推拉和近景，关系不变。
- **动态**：短冲击进入→标签出现→锁定；读取时安静，不持续弹跳和频闪。
- **禁忌**：三个以上竞争主体、伪造表情/破损、无依据的“实锤”、密集乱码、全图同饱和、廉价发光描边。
- **AI 生成约束**：真实品牌身份核对，冲突不造假；把标题可读区作为低冲突背景而非空白洞，横竖版重新构图。

## 007｜几何切面叙事海报

- **适用**：行业趋势、抽象概念、科普章节、轻量开场和竖版包装。
- **核心视觉公式**：有限几何形状＋两三块主色＋清楚方向/尺度关系，以平面切面讲事。
- **构图**：圆形、斜切面、轨道或抽象地形建立主轴；一个焦点，几何大小与位置对应概念。
- **色彩**：奶白配红蓝、黄绿或橙黑等有限组合，先选主色与冲突色，不把全部色板用齐。
- **材质**：平面纸张/印刷与低强度颗粒，形状边缘清楚；不混厚金属与液态玻璃。
- **光线**：平面均匀光或轻纸面阴影，明暗主要由色块设计，不追求写实三维灯光。
- **排版 / 图形**：Futura/Montserrat 类几何无衬线和合适中文黑体；排版遵守主轴，图形须有语义。
- **镜头**：正视平面，保持整体形状可读；必要时随阅读顺序平移。
- **动态**：遮罩切换、几何滑移、圆弧旋转，到位停住；可选低帧感动作采样，输出帧率仍按项目。
- **禁忌**：无意义圆球漂浮、彩色积木堆、柔糊渐变、过量景深、没有内容映射的装饰几何。
- **AI 生成约束**：锁几何边界与主色，图形不能随机变形；精确文字/图表比例后期实现，不让生成误差替代数据。

## 008｜暗黑超现实能量场

- **适用**：风险、未知技术、行业危机、巨大力量与个体关系的概念开场/封面。
- **核心视觉公式**：巨大自然/宇宙形态＋微小孤立主体＋少量光线，靠尺度与空域建立压迫和未知。
- **构图**：巨大形体与小主体的距离关系明确；负空间和前后层次服务尺度，不能只剩黑底发光圆环。
- **色彩**：近黑为主，深蓝、暗红、暗紫按主题择一；白/蓝/红微量亮点引导视线，暗部不全死黑。
- **材质**：雾、水、云、岩石或抽象有机体按情境选择，保持一套物理/艺术逻辑，不把所有材料混在一起。
- **光线**：低调背光或局部强源，有限体积层揭示体量；主体轮廓可读，能量亮度集中。
- **排版 / 图形**：标签极少，必要字使用清楚重体/衬线；不叠参数 HUD 破坏未知空间。
- **镜头**：广景、慢推/慢拉、低频尺度揭示；稳定地让观众理解相对位置。
- **动态**：一次主要能量涌动或缓慢扩散，小主体动作极少；不是满屏爆炸与相机震动。
- **禁忌**：糖果霓虹、英雄游戏海报、持续闪电粒子、糊雾掩盖几何、无明确主体的黑屏。
- **AI 生成约束**：巨大形态与小主体数量/位置连续；标为概念隐喻，不能当真实灾难或技术实拍。暗部也要有可见层次。

## 009｜全息玻璃梦境

- **适用**：未来硬件概念、AI 感知、柔和科技情绪、品牌包装和前瞻视觉。
- **核心视觉公式**：单一漂浮玻璃主物＋柔光空间＋边缘少量虹彩，让透明与折射本身构成主题。
- **构图**：中心或纵向聚焦，空间留白充分；少量陪衬给尺度和折射参照，避免透明物体层层塞满。
- **色彩**：银白、浅蓝、淡紫与微桃色，虹彩只随边缘/角度出现，不整幅七彩渐变。
- **材质**：有厚度与折射逻辑的玻璃/亚克力，可少量液态金属；透明物不是无厚度的塑料果冻。
- **光线**：柔棚光、背透和受控反射，保留亮部细节；折射色来自材质与角度，不给每层独立灯带。
- **排版 / 图形**：少量轻衬线或清楚无衬线，文字安静；Didot/Bodoni 类或中文细衬线可作方向参考，准确字后排。
- **镜头**：近景/微距或缓慢小角度观察，以折射关系为目的；焦点保证主物识别。
- **动态**：低幅漂浮、慢转或一次柔光掠过；同时只突出一种变化。
- **禁忌**：警告式酸性大字、密集参数、全屏虹彩、软胶熔化、没有结构的透明泡泡堆。
- **AI 生成约束**：锁厚度、边缘、物体数量和轮廓；反射随运动连续变化而非纹理爬动。真实产品不因梦幻风改变关键结构。

## 010｜复古光谱扫描

- **适用**：通信、信号、旧科技、光学、太空、系统异常和复古未来抽象镜头。
- **核心视觉公式**：高反差黑白主体＋一条有方向的光谱/扫描机制＋有限模拟信号痕迹。
- **构图**：主体结构清楚，扫描带沿确定方向穿过；水平切层、重复曝光层服务信号过程，不能占满整幅。
- **色彩**：黑白灰为底，局部光谱为唯一强彩色；克制彩虹范围，让扫描位置有辨识度。
- **材质**：胶片/模拟屏幕颗粒、扫描线、轻拖影；不同噪声尺度统一，不把画面糊成旧录像污块。
- **光线**：高对比影像与扫描发光分离，光谱经过才出现对应变化；主体暗部仍可认。
- **排版 / 图形**：VT323/Courier 类等宽信号标签配可读中文；读数必须有依据，无需数字时不用伪仪器 UI。
- **镜头**：固定屏幕/正视或有限局部推进；稳定参照便于观众感知扫描过程。
- **动态**：扫描经过→短拖影/错层→回到清楚画面；模拟抖动只短时出现。
- **禁忌**：全图彩虹、连续强频闪、黑白主体不见、现代玻璃卡片混贴、随机数字冒充检测结果。
- **AI 生成约束**：主轮廓不随扫描熔化；光学隐喻标为示意，不能声称是真实测量。视频明确扫描方向、次数与停止状态。

## 011｜复古系统故障界面

- **适用**：软件 Bug、平台机制、账号/隐私问题、旧互联网和系统异常叙事。
- **核心视觉公式**：旧系统窗口的明确操作关系＋局部像素故障＋一个可读的主状态。
- **构图**：主窗口先成立，少量次级窗口层叠；错误/状态集中一处，不能弹窗均匀铺满。
- **色彩**：系统灰、灰青、黑、经典蓝按主题选用，少量绿/紫作状态色；不默认现代霓虹渐变。
- **材质**：像素边、硬边框、ASCII/点阵与轻屏幕颗粒；不要厚玻璃阴影或写实金属窗口。
- **光线**：屏幕自发光和浅层级，不搭三维棚拍灯光；主体窗口对比清楚。
- **排版 / 图形**：Chicago/VT323/等宽系统风与可读中文黑体；菜单、错误文案有实际语义，重要字独立排版。
- **镜头**：固定屏幕平面，必要局部定位放大；无意义旋转会破坏系统感。
- **动态**：窗口弹出→像素错位/短错误反馈→冻结让人读；低帧感可作为局部动作方式，不能持续闪烁妨碍阅读。
- **禁忌**：现代圆角玻璃 UI、随机错误代码、伪造真实软件截图、每秒无限弹窗、完全不可读的乱码。
- **AI 生成约束**：机制示意与真实 UI 分开；若讲真实操作使用可靠截图和准确步骤。视频保持窗口位置、文字、数量受控，不随机生成新按钮。

## 012｜数据粒子装置

- **适用**：AI 数据、模型训练、网络节点、信息聚合、音乐化开场、抽象数据转场。
- **核心视觉公式**：黑色舞台＋有明确聚散逻辑的点云/碎片＋一个可识别装置或形态。
- **构图**：密集核心与稀疏空间有对比，点线围绕一个形体组织；避免满屏均匀撒点。
- **色彩**：黑底、白/青/绿等少量色系，强调色标定状态；大面积发光要受控。
- **材质**：点、线、薄片和少量文字碎片，不假装所有粒子都是写实玻璃球；颗粒尺度统一。
- **光线**：粒子有限自发光，Bloom 不吞轮廓；暗场仍能区分前后层级。
- **排版 / 图形**：Orbitron/等宽数字可作小标签，必要真实数据单独排；文字环仅在承载概念时使用。
- **镜头**：固定舞台或轻角度观察，让形体形成过程可读；不同时高速旋转装置和摄影机。
- **动态**：聚合→一次脉冲/状态变化→重组或停留，分阶段突出一个主动作；节拍服务主题。
- **禁忌**：所有点永久乱飞、闪烁淹没主体、随机波形、信息无关的数字雨、粒子数冒充统计量。
- **AI 生成约束**：锁主要形态与聚散方向；抽象点云不充当真实测量。代码实现需固定随机种子并支持按时间重建；AI 视频减少同时复杂动作。

## 013｜低多边形沙盘模型

- **适用**：园区、城市、生态系统、智能家居、空间网络和轻科普的场景关系解释。
- **核心视觉公式**：边界清楚的微缩地块＋有功能分区的低多边形对象＋可追踪连接。
- **构图**：等距/正交小场景，主功能区清楚；地块边界、道路与节点各有作用，细节密度受控。
- **色彩**：低饱和绿、浅蓝、奶白与棕灰；强调区域用一个清楚对比色，不做糖果玩具城。
- **材质**：纸/塑料模型观感、清楚多边形切面与统一厚度；保留设计模型感。
- **光线**：柔棚光、接触阴影、适量 AO；明暗说明体块，不要重电影雾与硬噪点。
- **排版 / 图形**：Nunito 类友好无衬线与清楚中文，节点标签少而准，连线不穿错对象。
- **镜头**：固定等距或轻俯拍，微量旋转只为揭示被遮结构；全局定位始终明确。
- **动态**：地块/模块依次组装→路径连通→读取；主过程推进时其他区域保持安静。
- **禁忌**：低幼玩具堆、随机建筑、真实地理比例误导、过度反光、无必要的弹跳与旋转。
- **AI 生成约束**：明确为场景示意；涉及真实地图/园区需资料约束，不编真实布局。连续帧锁建筑数量、道路连接和功能区位置。

## 014｜酸性机能竞速界面风

- **适用**：电竞、科技活动、竞速编号、栏目包装、强态度科技视觉、机能/游戏档案。
- **核心视觉公式**：酸性强色＋深黑硬底＋竞速网格/编号＋硬切拼贴，像工业信息与速度系统。
- **构图**：斜切色块、硬框、条码/编号、紧凑网格围绕一处主视觉；密度有梯度，焦点区不是所有边都亮。
- **色彩**：黑与酸绿主导，紫蓝可作第二色，热粉/红/橙只少量点缀。原风格比例可参考黑30%–50%、酸绿25%–40%、紫蓝10%–25%、小强调5%–15%，按项目删减，不要求多色同时满额。
- **材质**：半调网点、复印/印刷痕迹、工业包装、屏幕感与局部硬塑料；总体偏平面硬质。
- **光线**：清晰硬边和色块反差为主，少量高光；不做深空间柔梦棚拍。
- **排版 / 图形**：Eurostile/DIN 类压缩宽硬字体、中文重黑体、OCR/等宽小标签；编号/条码/刻度表达真实内容或明确装饰角色。
- **镜头**：正视或很轻倾斜，固定/微推；信息不随着摄影机漂移旋转。
- **动态**：色块短促切入、编号跳变后锁定、条码扫过、框线绘制、瞬时故障吸附；随后读图停留。
- **禁忌**：柔软果冻弹跳、慢梦幻漂浮、完整写实 CGI 场景、无意义密集 HUD、所有文字同大、默认蓝紫科技模板。
- **AI 生成约束**：保硬边与主色分工，避免荧光涂满全部对象；最终编号/文字准确后排。视频不能无逻辑切换标签和人物身份。

## 015｜动画侦探线索板

- **适用**：硬件调查、配置差异、新品线索、拆机复盘、价格追踪、真假升级与发布前瞻。
- **核心视觉公式**：动画感调查舞台＋被照亮的一张主线索＋有逻辑的少量连接，观众跟着证据推理。
- **构图**：中心线索与周边资料有强弱，连线端点明确；约三到五个可辨节点足以开始，其他逐步揭示。
- **色彩**：深墨绿、蓝黑、暗红/棕为底，暖红/橙/象牙白在光区；可参考大部分暗色、少量暖光、纸面与强调的分配。
- **材质**：插画纸卡、木面、胶片、绘制道具，保留动画/编辑感；不是写实犯罪现场照片墙。
- **光线**：一盏可解释的台灯/聚光，纸面明亮而周边低调；光照引导当前线索。
- **排版 / 图形**：清楚黑体与等宽标签，状态显式区分“已确认/推测/待核验”；红线表示具体关系，不暗示未经证实的指控。
- **镜头**：正视或轻俯视，局部推进/平移聚焦线索；改变景别前先给整体定位。
- **动态**：灯光揭示→卡片贴上→连线生成→结论聚焦，每阶段一个重点；不要全板一起闪动。
- **禁忌**：恐怖血腥、阴谋论符号堆、伪造证据、金属三维大字、几十条随机红线、未经证实暗指真实人/品牌违法。
- **AI 生成约束**：可生成调查板底板与示意道具，真实截图/引文另合成。人物/节点/连线数量稳定，资料身份与来源可核验。

## 016｜人工 CG 渲染

- **适用**：消费电子商业 CGI、芯片/算力/存储概念、三维结构解释、视觉重构、封面底图、图生图/图生视频与粗动效最终渲染。
- **核心视觉公式**：有设计意图的硬表面建模＋有限且清楚的 PBR 材质＋专业人工布光＋虚拟摄影机。目标是“像三维艺术家精心做出的渲染作品”，不等于原图写实翻版。
- **构图**：以文案关系和主体识别为锚，自主设计主次、前后空间、尺度和遮挡。可用悬浮、爆炸结构、阵列、切面、几何底座，但必须表达内容。用户要求重构时，不照抄原图机位/摆放/背景；要求保留时明确锁定项。爆炸结构必须还能看懂零件归属。
- **色彩**：中性色与产品色为主，限定一套主色和一个强调；保留金属、塑料、玻璃自身色响应。冷暖可用于布光分层，不全场蓝紫霓虹，不用过曝洗掉材质。
- **材质**：造型具有可理解的挤出、内凹、布尔、阵列与统一小倒角；结构细节有功能依据，主尺度与微细节分明。常用哑光工程塑料、喷砂/阳极金属、陶瓷、烟色玻璃等，通常两三种主材质足够。金属度、粗糙度、折射率、透射、厚度与吸收有明确区别；微表面变化用于控制高光，不以随机划痕污渍冒充真实。玻璃有壁厚，金属不是带灰颜色的塑料。
- **光线**：主区域光建立体积，弱补光保暗部，必要轮廓光分离主体，背景光独立克制。灯光像能摆出的 Studio Light Rig，每个主要高光有来源。接触阴影位置正确，AO 只加强接缝不涂黑所有角落；反射形状有设计感。GI 与反射/折射干净，亮部平滑回落，可参考 ACES/Filmic 的观感但不能声称实际用了某渲染器/色彩流程。
- **排版 / 图形**：字、Logo、技术标注尽量独立图层，准确字体与识别特征优先；说明引线对应真实或明确示意的部位。造型表面不塞随机机械编号、虚构电路和“技术感”乱码。
- **镜头**：产品可参考50–100mm观感减少畸变，关系夸张时才选24–35mm广角观感；工程解释可用正交。焦段是视觉指导，不是假称图像带有真实相机参数。景深服从主体清晰和物理焦面，不能把边缘选择性糊掉掩盖结构。
- **动态**：Dolly/Truck/Orbit/Crane 选一种有意义的主运动，或让物体完成一次展开、聚合、旋转到位；克制惯性，留终态。模型拓扑、厚度、数量和贴图稳定，阴影/反射随运动合理连续变化；不能为了“稳定”冻结所有反射。
- **禁忌**：照抄原图当重构、摄影写实替代人工三维设计、随机机械细节、无限倒角、果冻金属、无壁厚玻璃、过曝 Bloom、所有边自发光、过量真实环境杂物、模糊遮错、伪称真实技术拆解。
- **AI 生成约束**：先列必须保留的身份/关系，再明确可重设计的构图、造型、机位、材质和灯光；不写互相冲突的全保留/全重做。粗动效仅给运动与布局，锚点给最终外观。真实产品细节先核参考，内部不可见结构只作明确示意。首帧到尾帧锁几何、Logo/字的外置策略和主光方向；画面不因“像人工渲染”而强加噪声、污渍或照片感。

## 017｜暗黑剪影概念叙事 CGI

- **适用**：历史/商业/科技史的概念重建，权力、资本、工业、组织与社会关系；缺少真实影像但需要看懂场景和行为的叙事 B-roll。
- **核心视觉公式**：匿名哑光人物剪影＋可辨的极简三维舞台＋一组戏剧主光＋符号化动作。观众必须看懂“什么地方、谁在做什么、是什么关系”，不能只看见漂亮黑影。
- **构图**：前中后关系清楚，用门、窗、桌、机器、台阶、队列等约三到五个场景锚点交代身份和空间。主行为处于焦点，人物之间的站位、距离、尺度和遮挡表达组织关系。负空间有目的；巨大与微小的对比可用，但不能让人物腿手与背景融为一团。
- **色彩**：黑、炭灰、石墨与低饱和环境为主，选冷白、琥珀、暗蓝或暗红之一做主要光色/语义强调。暗部层次能辨认场景，避免整体压成纯黑或过度彩色霓虹。
- **材质**：人物是无脸、无皮肤细节的哑光石墨/深灰体块，保留姿态和衣着轮廓的必要识别；不是反光黑塑料玩偶。场景可用混凝土、暗金属、木面与少量玻璃，粗糙度克制统一；道具数量少但身份清楚。
- **光线**：一扇亮窗、一扇门、顶灯/聚光等可解释主源建立明暗和故事方向；必要微补光分开肢体与背景。体积光与薄雾只让光路/距离可见，不用浓雾隐藏不成立的场景。光源、投影方向与人物接地稳定，亮区集中在主行为。
- **排版 / 图形**：画面尽量少字，必要说明用独立字幕/简短标签；不在场景塞大量界面、浮空参数和伪文件字。文件/信件是叙事道具，不自动具备真实证据效力。
- **镜头**：广景或中远景优先看清场景与关系；慢拉揭示全局、横移揭示人物关系、轻推关注动作，也可用有限2.5D视差。避免纯黑背景人像特写；景别变化必须保留空间定位。
- **动态**：一次极简动作，如递交文件、转身、缓步进入、按下控制、抬头望向光源；也可只用镜头揭示关系。动作先后清楚，不同时让人群、机械、灯光和相机都忙起来。雾尘低速，主动作结束后留停顿。
- **禁忌**：补出真人脸和皮肤、超级英雄/恐怖游戏感、黑塑料高光人偶、全黑无场景、霓虹赛博 HUD、浓雾遮关系、随机增加人物/肢体、毫无叙事的站桩剪影。
- **AI 生成约束**：Prompt 必须写场景锚点、人物数量与站位、唯一关键行为、主光位置以及必须可见的关系；锁人物轮廓与道具，不在视频中变成另一个场景。与016结合时只借其模型/材质/布光完成度，保留匿名剪影叙事；与008结合仅借尺度和气氛，不让能量奇观吞掉场景。历史/商业再现显式标概念重建，不能冒充真实录像或确定的真实人物行为。
