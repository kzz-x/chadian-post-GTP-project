# 【差点封面】

- **负责什么**：硬件视频封面的卖点、主视觉、视觉冲突、阅读路径，16:9 与 3:4 双版设计，方便后期叠字的成品底图。
- **何时调用**：用户要封面、缩略图、封面底图、双版标题布局，或现封面需要改稿。
- **何时不要调用**：整篇文案未请求封面时不自动加做；片内信息图和普通镜头不使用封面标题区规则。
- **常见触发词**：封面、标题区域、横竖版、16:9、3:4、无大标题底图、点击欲、主视觉、双芯。
- **输入**：主题与结论、标题或候选、主体参考、风格/已批准母版、横竖标题区示意、需要保留或修改的部分。
- **输出**：B交产品真实性状态、真实产品参考板、设计参考板、同卖点横竖构图、标题区/阅读路径、小字清单与两版完整Prompt；C交指定底图与实际检查，区分已完成和待制作，并明确产品是“真实参考锁定 / 后期PS替换 / 仅示意”。


## 阶段、必交字段与改稿约束

按【差点后期】阶段控制。“设计封面/做封面”默认进入B设计，不直接生图；“生成这版底图”或明确“直接生成、无需确认”才进入C。先实际读取本文件与选定风格章节，列3–5条当前约束。只说“按差点封面”不算完成调用。

### Research First：新封面默认先研究、筛参考，再设计

除非用户明确说“跳过调研 / 直接做 / 按已确认参考执行”，每个**新的封面需求**必须先完成以下流程，不能从需求直接跳到设计方案、Prompt 或生图：

> **需求理解 → Product Accuracy Gate → Product Reference Board → Design Research → Reference Board → 用户筛选 → Design DNA → Art Direction → Prompt / 素材 / PS 合成 → 生成与产品准确性复核**



### Product Accuracy Lock：产品真实性锁（产品类封面强制）

只要封面涉及**具体品牌、具体型号或需要型号级识别的真实产品**（手机、汽车、芯片、显卡、耳机、相机、家电、配件、工业设备等），自动触发本锁。它的优先级高于“画面完整”“一次生成完整度”和“看起来像那个产品”。

**第一原则：产品准确性 > 画面完整度。** 宁可留空、做占位、只生成背景/包装层，也不要用“长得差不多”的 AI 产品冒充准确型号。

每次封面阶段输出——B0 / B1 / B2 / C / D改稿——都必须显式给出一行：

`Product Accuracy Status：LOCKED / PARTIAL / MISSING / BACKGROUND-ONLY｜依据：用户参考 / 官方图 / 已核验真实图 / 无｜下一步：继续 / 补参考 / 后期PS替换`

状态定义：
- **LOCKED**：已有足够清晰、型号一致、角度可用的真实参考，可约束最终主体。
- **PARTIAL**：只锁定了部分角度/颜色/结构；未覆盖的视角、接口、镜头、铭文等不得擅自补成“确定外观”。
- **MISSING**：没有可靠真实参考。可以继续做构图和示意，但生成产品只能视为占位，不能当最终准确素材。
- **BACKGROUND-ONLY**：主动不生成最终产品主体，只做背景、场景、结构草图、光影、装饰和主体承托关系，最终由用户/后期把真实产品 P 上去。

**在每个阶段都提醒一次，而不是只在开头提醒。** 提醒要短但明确：如果当前不是 LOCKED，应告诉用户“AI 生成的具体产品可能在镜头、Logo、接口、比例、按钮、颜色和结构上不准确”，并主动给出两条路径：`补充/选定真实产品参考` 或 `继续做背景/占位，后期PS换真产品`。用户没有补参考并不自动阻塞流程；只要其明确要求继续，可继续，但必须维持对应状态和风险标记。

#### Product Reference Board：真实产品参考板

产品类封面在审美 Reference Board 之外，必须单独建立 **Product Reference Board**，两者不得混为一谈。优先搜：
1. 品牌官网产品页、官方媒体包、官方发布会/宣传图；
2. 品牌官方商城或官方电商页；
3. 可信媒体评测/实拍，且必须核对到同一型号、颜色、版本；
4. 高质量零售/图库只作补角度来源，型号仍需回到官方或可信来源核验；
5. Google Images / Google Shopping 可用于扩展角度，但不能仅凭搜索缩略图认定型号准确。

默认尽可能多收集**真正有用且不重复**的准确产品图。产品是主视觉时，建议至少覆盖：正面、背面、侧面、关键局部、与最终构图接近的 3/4 角度；能找到时优先 8–20 张有效候选，而不是为了数量堆重复图。新品、未发布产品、传闻机型或资料不足时，必须明确“现有公开图无法保证最终量产外观”。

每张产品参考至少标：
`来源/链接｜型号/版本/颜色｜角度｜可锁定的外观特征｜仍不确定的部分｜是否可直接用于PS合成`

同时主动提醒用户：**如果手里有官网原图、实拍、透明PNG、产品摄影或自己认可的准确角度，请直接提供；用户给的准确参考优先级最高。** 如果用户后面补图，立即把状态升级并重新检查构图是否需要适配。

#### 三种产品制作模式

产品类封面必须明确选用其一：
- **A｜Reference-Locked Full Generate**：已有 LOCKED 参考；生成时产品主体必须绑定指定参考，不能重设计镜头数量、接口、比例、Logo位置、结构和颜色。
- **B｜Background + Real Product PS（默认优先）**：生成背景、场景、光影、材质、冲击元素、承托结构与遮挡关系；真实产品后期 PS 置入。对手机、汽车、显卡、相机等高识别产品，若模型难保证准确，默认优先此模式。
- **C｜Approximate Mockup / 示意占位**：用户明确要先看整体或直接生成但没有可靠参考时允许。必须在生成前后都标注“产品仅为构图/光影示意，型号细节可能不准确，最终需参考图替换或手动PS校正”。

即使用户明确说“直接生成 / 不用等参考”，也只是允许跳过等待，不代表产品准确性自动成立；生成后仍要再次提醒当前状态和替换建议。

**Design Research 必查维度**：构图 / 网格 / 负空间 / 比例；视觉层级与阅读路径；色彩关系与面积比例；字体 / 字形与图像关系；产品摄影 / 裁切 / 镜头角度；Photoshop 合成 / 拼贴 / 蒙版 / 遮挡；材质 / 纹理 / 光影；编辑设计、海报、品牌 KV、工业目录、技术手册等跨领域方法；与本期主题相关的视觉隐喻。

**参考来源优先级**：Behance、It's Nice That、BP&O、The Brand Identity、Fonts In Use、Are.na、SAVEE、Designspiration、专业设计工作室官网 / 品牌官方 Campaign / KV；Google Images 用作跨站补充。Pinterest、小红书等可补充，但不得成为唯一审美来源。

不得只搜“某产品 + thumbnail / 科技封面”。必须跨领域找设计方法，例如按主题组合搜索 industrial editorial design、technical manual graphic design、exploded view poster、Swiss editorial layout、engineering catalogue design、product photography composition、experimental typography、museum exhibition poster 等。

默认收集 **12–20 张**真正有差异、有用途的参考图并去重，至少分为：
1. 构图参考
2. 配色参考
3. 创意参考
4. 材质与细节参考
5. 字体排版参考
6. 摄影 / PS 合成参考

每张参考必须写：`来源/链接｜参考类别｜这张具体值得借什么｜不应照搬什么`。禁止只写“高级 / 有设计感 / 很适合”。

**Reference Board 输出后停止。** 用户可跨图选择，例如“A 的构图 + D 的配色 + F 的字体关系 + H 的材质”。筛选后把参考图拆成可执行的 **Design DNA**：主体占比与位置、网格 / 负空间、色彩面积、字号级差、遮挡关系、材质、纹理、光影、局部打破规则的位置等。

随后默认给 **2–3 个真正不同的 Art Direction**。差异必须来自构图机制、视觉隐喻或设计系统，不能只是换颜色。方向锁定后，才允许写最终 Prompt、素材清单、PS 合成方案并进入生成。

仅以下情况可跳过完整 Reference Board：用户明确要求跳过；用户已提供足够明确且已确认的参考；同一项目连续改稿且 Art Direction 已锁定。即使跳过，仍必须遵守人工 PS 制作感、主体识别、设计层级和缩略图可读性。

**B固定设计卡**：Product Accuracy Status；Product Reference Board 与已锁定/待补的产品参考；研究结论；Reference Board 与用户选中的审美参考；Design DNA；Art Direction；主题结论/卖点；唯一冲突；主主体及辅助元素删减；产品制作模式 A/B/C 与理由；表现模式与理由；风格的具体色彩/材质/光线；16:9构图；3:4重构；两版标题兼容区；小字清单；保留项/检查项。**最终 Prompt 不在 Reference Board 阶段提前输出，只有用户筛完参考并锁定 Art Direction 后才生成。**用这套顺序输出，不能只交图片或一堆泛泛形容词。

小字清单格式：`准确内容｜为什么需要｜位置/信息层级｜直接生成或后期合成｜依据/待核项`。允许为清楚识别而建议少量标签，不要求全部为空；不为凑数量加标签。最终标题可另列建议，但不要放进“要求绘制的底图文字清单”。

**完整Prompt必须在生成前交出**，包含 Product Accuracy Status、产品参考绑定/占位策略、主体/关系、构图、颜色、材质与光照、标题兼容区、相关小字安排及针对性禁项。具体产品若是 LOCKED，必须写明以哪张参考为唯一/主要外观依据；若非 LOCKED，必须写明产品仅占位或产品区域留给后期PS，不得把模型自由生成的产品描述为准确成品。不要只写“用000风格”；不要让工具自行从整篇口播中挑字填画面。禁止大标题的同时明确允许哪些少量有效小字；需要精确呈现的字使用后期图层，不能一律让图像模型猜。

已确认后，文字策略、主体身份、标题区和画幅成为保留项；“不好看”不能撤销它们。构图/光照可以在修改方案中调整，但不得回到“大标题＋各国物件平均摆满＋地图/护照/机场全塞”的默认模板。

### 双版与文字的正反例

合格：无最终大标题；主体附近有少量准确的小号Type E/Type F标识，帮助区分且从属；横版中下部、竖版下半部仍能后期排标题。

不合格：大标题、副标题、各国介绍、旅行口号同时烘焙；或把“无大标题”误写成禁止所有有用标签；或小字虽小，却散落全画面成为杂乱文字墙。

图像模型难以准确表现插孔/结构时，优先切到 **BACKGROUND-ONLY** 或用真实产品资产合成，只生成背景与包装层；禁止用“像某插座/某手机/某显卡”的错误几何冒充准确主体。若用户仍要求先生成，则明确标为 Approximate Mockup，并在生成后提醒替换真实产品。缩略图看不出冲突时先改主视觉，不继续叠护照、地图、飞机和参数。

## 1. 核心公式

**一个主卖点＋一个主主体＋一个视觉冲突＋一条阅读路径。**

主卖点从结论中提取，不把整篇内容塞进封面。视觉冲突可以是强弱、远近、新旧、限制与突破、承诺与现实；不能靠无依据的破损、爆炸、愤怒表情制造虚假结论。“能飞吗”不默认画火箭，“突破”不默认碎玻璃，“AI”不默认机器人。

主主体可是一件产品，也可是构成一个整体的双芯/双机组。双主体用共用外框、前后层级、统一方向和光照组织，必要时轻微交叠；不能像两个互不相关的电商图并排粘贴。涉及真实数量或体积比较时，不能用失实放大表达结论。

先用一句话确定观众先看到谁、再读到什么、最后感到哪种冲突。缩成手机缩略图仍能认出主体与关系，才进入细节制作。

## 2. 横竖版标题区：按用户示意默认执行

本规则采用用户在本次重构中提供的两张红色区域草图。它们表达大致区域，不是精确像素或固定比例模板。

| 版本 | 默认标题区域 | 主体与背景处理 |
|---|---|---|
| 16:9 横版 | **中下部、水平居中的宽横向区域**；有一定高度容纳主标题，底部仍留余量 | 核心识别与最强细节优先放上部/上中部；标题可叠主体非关键下缘，不能压住关键 Logo、接口或冲突点 |
| 3:4 竖版 | **下半部（中线以下至偏下部）、居中横向展开的较高标题区**；通常比横版更适合分行，底部留余量 | 主体在上半部/上中部重新组织，必要时变前后或上下关系；标题不是贴底字幕条 |

这一区域是“后期可读的文字叠加区”，不是白块、空洞、硬切割面板或固定底部 30%。背景要完整延伸，保留低对比的材质/结构；降低高频细节、强高光、密集线条和局部色差。不能用一大块无意义渐变糊住半张图来留字。

标题字数、分行与具体主体可使区域略作调整，但默认位置应忠于用户示意。设计前先以真实标题或相近长度的占位文字验证遮挡；占位框/红色斜线只用于辅助预览，不进入成品底图。没有标题时用合理长度测试并说明未定，不强行发明最终标题。

用户后续给更精确模板或要求放侧边时覆盖此默认。不要恢复旧版固定左上 Logo 区、固定下方百分比等机械规则。

## 3. 双版不是裁切关系

横版默认 1920×1080；竖版可按 1080×1440 设计，工具实际输出能力不同则报告实际尺寸再适配。两版共享卖点、主体身份、色彩、材质和设计语言，重新安排主体大小、相对位置、冲突焦点和标题区域。

横版适合横向聚合和适度斜向关系；竖版可转为前后层叠、上下递进或更集中的主体组。不能将横版中心裁切后，主体被切掉再声称“竖版已完成”。如果同一底图确能重组，需要独立图层或重新生成/合成，并查看两版成品。

普通镜头中央 62% 核心区不能取代封面构图。两版分别缩略检查主体识别、文字容纳、阅读顺序和边缘余量。

## 4. 默认视觉与可选方向

未指定时，硬件封面优先**科技媒体编辑设计、Photoshop 手工合成、简约平面/半平面 2.5D**。用真实硬件抠图、蒙版、硬边层叠、明确明暗和少量纹理建立完成度，不自动变成电影环境或游戏海报。

### 人工 PS 制作感：一级硬约束

“像专业设计师在 Photoshop 中手工完成”是默认强约束，不是可选风格。核心流程：**AI 负责生产素材，PS 逻辑负责组织画面。** 当“视觉华丽 / 一次生成完整度”与“人工 PS 制作感”冲突时，优先人工 PS 制作感。

生成与合成必须能读出明确人工设计决策：真实主体抠图、局部蒙版 / 遮挡、素材拼贴、前中后景层级、局部调色和锐度差异、光影匹配、工程标注 / 编号 / 箭头 / 框线、扫描 / 印刷 / 纸张 / 贴纸 / 半调 / 颗粒等受控纹理。允许不完全对称、真实素材边缘、局部透视 / 清晰度轻微不一致，只要是设计选择。

默认禁止明显 AI 成片感：全图被同一种梦幻 / 光滑 / CG 滤镜统一；塑料 / 蜡质材质；无意义粒子、电路、HUD、随机伪文字；不存在或似是而非的结构细节；过度锐化和统一高光；廉价蓝紫霓虹 / 泛光；为了“高级”堆没有信息用途的装饰；背景每个区域复杂度都一样。

图片模型优先生成可拆分的主体、背景、结构草图、局部元素和光影 / 纹理素材；不要默认一次生成不可拆解的最终成片。最终 Prompt 与验收必须检查：**这张图是否像真实设计师在 PS 里排过素材、做过蒙版、层级和局部修饰，而不是 AI 自动生成一个完整世界。** 如果后者更明显，视为未通过并重做。

三种可用方向按内容择一：编辑合成是常用默认；产品材质重要时用半写实产品呈现；只有故事空间本身能表达卖点时用叙事场景。用户指定 016/017 或明确商业 CGI 时服从指定，不强制回到平面。

背景通常只保留两三类与主题相关的结构，例如芯片结构、资料卡、几何框；超过五个独立装饰对象先删减。主视觉足够集中，装饰服务定位、关系和层次，不靠满屏 HUD 伪装专业。

平面 Prompt 不叠加 cinematic、Octane、强体积雾等相互冲突的术语。手工感来自切边、投影、适量半调、纸面或错版的统一逻辑；不是每个物体都加白描边、胶带和脏纹理。

## 5. 真实主体与文字

具体产品/品牌必须先触发 **Product Accuracy Lock**，并用【差点素材】取真实参考；多角度合成仍要检查身份、比例、镜头/接口数量、按钮、Logo/铭文位置、颜色与关键结构。优先把用户提供的准确原图/实拍/透明PNG与官方图作为锁定依据。新品、未发布或公开信息不足时保留对象与待核验状态，不擅自把品牌匿名化，也不让 AI 发明确定外观。没有足够参考时，默认优先 BACKGROUND-ONLY，让用户后期把真产品 P 上去；若用户选择直接生成，则只能作为示意占位。

**默认不生成最终大标题和杂乱无关的字，不是完全无字。** 最终大标题后期添加；禁止假标题/占位标题、乱码、无关口号、随机代码和装饰字墙。允许少量准确且与当前主题直接相关的小号标签、型号、参数、品牌标识，作为三级/四级信息，不抢主体、不占满标题区；重要准确文字优先真实图层后加。真实产品原有必要铭文按参考保留，不借此新增字。没有功能的小字就删除，不以“科技感”作为用途。

默认只选一套强识别标题字体加一套辅助数字/标签字，不让多个字族互抢。中文重标题优先合适的黑体，数字用统一等宽或窄体；具体按风格卡与实际字体授权选择。

## 6. 执行与改稿

先实际读文案、现图与来源，定卖点和主体关系。若涉及具体产品，第一步先显示 Product Accuracy Status，建立 Product Reference Board，并提醒用户可补自己的准确参考或选择后期PS真产品。新封面进入B后，先交 Product Reference Board（如适用）+ Design Research + Reference Board 并停止；用户筛完参考后，在 B1 再次显示 Product Accuracy Status，再交 Design DNA + 2–3 个 Art Direction 并停止；方向锁定后，在 B2 再次确认产品模式 A/B/C，才交一套横竖设计及两版完整Prompt。C收到明确生成指令才做图，不在“设计个封面”后直接随机出三张。

先摆主体与标题测试区，再做色彩和光影，最后补受控纹理。进入 C 前再次显示 Product Accuracy Status；实际生成/合成底图后分别检视：主体身份、型号关键结构、冲突、标题区可读性、完整背景、横竖关系。若产品状态不是 LOCKED，成图后必须再次提醒“产品仅示意/待PS替换”，不能因画面看起来像真机就升级为准确素材。需要参考标题位置，可另给带框/占位标题的预览，成品底图保持干净。

用户说“不好看”进入D并联动【差点视觉】，先定位最多三个具体问题，列影响、改法和保留项，交修改方案后停止；明确要求“按方案改图”才执行。已满意的主体、字体和色彩不要全部推翻。说“标题位置按这两张图”，更新布局默认，不能被旧 Mini/Lite 的文字规则覆盖。

## 7. 最小交付

B分三段交付：B0 先给 Product Accuracy Status；产品类额外交 Product Reference Board，再交 Design Research + 12–20 张审美 Reference Board 并停止；B1 再次给 Product Accuracy Status，交用户选中参考的 Design DNA + 2–3 个 Art Direction，并提醒“补准确产品图 / 后期PS真产品”路径；B2 再次确认 Product Accuracy Status 与产品模式 A/B/C，在方向锁定后交一句卖点、一个主体冲突、表现模式与具体风格约束、两版构图/标题区、相关小字清单、横版完整Prompt、竖版完整Prompt、检查标准；交完停止。C交获授权版本的底图、对应Prompt和实际检查；默认先验证横版方向，通过后再制作竖版。用户明确“同时生成双版”可直接双版；尚未生成的版本标待制作，不用Prompt冒充图片。

验收：先复核 Product Accuracy Status；具体产品必须检查型号、比例、镜头/接口/按钮、Logo/铭文、颜色与关键结构，非 LOCKED 成图不得宣称准确，必须保留“示意/待PS替换”提示；无最终大标题误烘焙，无乱码/无关字/杂乱字墙；有用小字准确且从属；两版主体可认；标题区符合用户示意且不压关键内容；背景完整；无假 Logo/伪参数；缩略图主次清楚；不只是机械裁切；**无明显 AI 成片感，能读出人工抠图、蒙版、图层组织和局部修饰逻辑**。如果整体更像 AI 一次生成的完整世界，直接判定未通过。失败先修布局和主体关系，再修质感。
