# Prompt编写规范

生成类Prompt不追求越长越好，而追求**约束分工清楚**。

## 静帧Prompt

推荐顺序：主体身份 → 内容关系 → 构图 → 机位 → 场景 → 材质 → 主光 → 色彩 → 风格 → 文字策略 → 必须保持 → 必须避免。不要用8K、masterpiece、award winning、cinematic、ultra detailed等词替代真正设计。

## 视频Prompt

通常3–5句即可：外观锚点、唯一主动作、明确摄影机运动、节奏“进入→变化→停留”、连续性约束、3–5个最容易失败的禁项。

不要同时要求“完全保持原视频所有视觉”和“彻底重做所有材质和场景”。明确：**动作参考负责运动；锚点负责外观。**
