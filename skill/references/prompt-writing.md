# Prompt编写规范

Prompt 不追求越长越好，而追求：**该锁的锁住，该放的放开。**
创作阶段少控制，修改阶段再精确控制；不要把设计决策和施工步骤一次性全部塞给 Agent。

## 1｜Prompt Freedom Mode

### P1｜CREATIVE_BRIEF（艺术家模式）
用于探索、找惊喜、测试模型自身的审美与 Motion Design 能力。

只给：
- 目标 / 要表达的关系；
- 参考图、参考视频或视觉方向；
- 2–5 个真正不能错的硬约束；
- 明确禁项。

不要写逐帧时间、逐层施工、坐标、完整技术步骤。结果视为候选方案。

### P2｜DIRECTED_CREATIVE（导演模式，默认）
用于大多数正式创作和第一版可用结果。

控制：
- 意图；
- 视觉方向；
- 节奏与关系；
- 必须满足的约束；
- 验收标准。

但让 Agent 自己决定具体构图微调、Motion 细节、转场方式和实现方法。
**默认从 P2 开始，不默认从 P3 开始。**

### P3｜EXECUTION_SPEC（执行规格模式）
用于设计已经收敛后的精确执行：
- 局部修改；
- Bug 修复；
- 精确复刻已确认结果；
- 工程化 / 模板化；
- 参数、结构、技术实现必须确定的任务。

只把需要确定性的部分写细，不要把所有维度一起锁死。

## 2｜阶段路由：Explore → Select → Converge

- **B 设计早期 / 探索方向**：P1 或 P2。
- **B 已选定方向 / C 首次正式制作**：默认 P2。
- **C 精确落地 / D 修改与修复**：P3。
- 用户明确说“让 Agent 自己试 / 看它能做到什么程度 / 自由发挥”时，优先 P1。
- 用户已有明确参考、Visual Anchor 或成熟模板，但仍希望 Agent 有设计判断时，优先 P2。
- 用户要求“只改这里 / 一模一样 / 按这个关键帧 / 不要动其他地方”时，直接 P3。

第一次结果偏离时，优先**只收紧失败的那一个维度**，例如构图、节奏、主体行为或文字关系；不要立刻把 Prompt 膨胀成逐帧规格书。

## 3｜Constraint Budget

一个 Prompt 最好明确三层：

1. **LOCKED｜硬约束**：事实、身份、已确认构图/文字、必须保持、交付格式。
2. **DIRECTED｜方向约束**：氛围、视觉语言、Motion 气质、节奏、阅读关系。
3. **FREE｜自由区**：具体实现、局部转场、细节 Motion、工程手段。

如果 FREE 几乎为空，先判断是否真的需要 P3；如果不是，说明写得太死。

## 4｜静帧 Prompt

需要精确视觉设计时，推荐顺序：主体身份 → 内容关系 → 构图 → 机位 → 场景 → 材质 → 主光 → 色彩 → 风格 → 文字策略 → 必须保持 → 必须避免。

但 P1/P2 不机械补齐所有字段。参考图已经说清的内容，不重复翻译成大量坐标和形容词。

不要用 8K、masterpiece、award winning、cinematic、ultra detailed 等词替代真正设计。

## 5｜视频 / Motion Prompt

P1 通常几句话即可：表达目标 + 参考 + 主体关系 + 关键禁项，让模型自己设计运动。

P2 通常只需要：
- 外观 / Visual Anchor；
- 唯一主动作或核心 Motion 关系；
- Timing / Audio / Marker 依据；
- 连续性与已锁定项；
- 3–5 个最容易失败的禁项；
- 验收标准。

P3 才补具体帧点、曲线、路径、关键帧、Expression、Parent、Effect、CTRL 或结构要求。

不要同时要求“完全保持原视频所有视觉”和“彻底重做所有材质和场景”。明确：**动作参考负责运动；锚点负责外观。**

一句话：**先让 Agent 设计，再选择，再把选中的部分做准。**
