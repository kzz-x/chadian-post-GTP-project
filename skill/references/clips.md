# 【差点片段】

职责：完整AI镜头、CGI、概念B-roll、历史/未来重建、视觉锚点、图生视频、粗动效最终重渲染。

## B固定设计卡

`原文/关系｜主体/场景｜起始/变化/终态｜构图/机位｜风格/材质/光线｜锁定项/可变项｜真实参考缺口｜画幅/时长｜完整静帧Prompt｜完整视频Prompt`

## 默认流水线

**先锚点，再视频。**

1. 定关系、主体、场景、构图、光源、材质、动作终点。
2. B阶段交静帧Prompt+视频Prompt。
3. C获授权后生成一张锚点。
4. 先检查锚点。
5. 锚点成立后再进入视频。
6. 视频检查身份、数量、方向、连续性。

默认一张锚点够用，复杂前后状态才加首尾帧/多关键帧。

## 粗动效→最终渲染

先读取实际视频，记录构图和相对位置、占位元素对应什么、元素运动路径、摄影机运动、节奏/停顿。

分工：**粗视频负责运动与时间；锚点负责最终外观；文案负责内容含义。**

继承相对位置、出入方向、遮挡关系、运动路径、先后顺序、节奏和明确机位；重新设计最终造型、材质、表面、灯光、阴影、反射、背景和场景。不要只给原来的方块“加金属滤镜”。
