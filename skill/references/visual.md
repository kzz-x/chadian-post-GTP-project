# 【差点视觉】

职责：文案关系→画面关系；创意、构图、主次、去AI味、多镜头统一、视觉锚点、已有画面诊断。

## 先找关系，再找物体

先补全：**观众看完这个画面，应理解「谁/什么」相对「谁/什么」发生了「怎样的变化或关系」。**

| 文案关系 | 画面机制 |
|---|---|
| A比B更大/更快/更省 | 同基准并列、共同起点、状态切换 |
| 因为A所以B | 一条方向明确的因果路径 |
| 从旧到新 | 同对象状态变化 |
| 整体与局部 | 先定位，再局部展开 |
| 瓶颈/限制 | 可见容量、路径、通道约束 |
| 规模/权力/依赖 | 主从尺度、空间站位、输入输出 |
| 证据/不确定 | 真实证据卡 + 明确状态 |

避免自动隐喻：突破≠必须碎玻璃；起飞≠必须火箭；AI≠必须机器人；瓶颈≠必须画瓶子。

## 构图

先确定第一眼、第二眼、最终记忆点。骨架从中心聚焦、左右对比、上下因果、斜向推进、环绕核心、前后尺度、局部放大中择一。一个镜头一个主视觉。

## 去AI味

去AI味不是统一加噪点，而是减少无依据与不一致：删除无功能随机细节；区分金属/塑料/陶瓷/玻璃；只保留有来源的主光与轮廓光；减少过度景深；删除无意义HUD；统一透视、接触阴影、颗粒和切边；画面精致但没内容时回到文案关系；视频漂移时锁几何/标识/数量并减少动作。
