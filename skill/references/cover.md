# 【差点封面】

核心公式：**一个主卖点 + 一个主体组 + 一个视觉冲突 + 一条阅读路径。** 不把整篇文案塞进封面。

## B固定设计卡

必须包含：主题结论/卖点；唯一冲突；主主体；辅助元素删减；表现模式与理由；具体色彩/材质/光线；16:9构图；3:4重构；两版标题兼容区；小字清单；横版完整Prompt；竖版完整Prompt；保留项/检查项。

## 文字策略

默认**不生成最终大标题、标题占位字、乱码、无关口号和杂乱字墙**，但不是完全无字。允许少量准确、相关、有明确用途、从属层级的小号型号/参数/标签/品牌标识。重要准确文字优先后期真实图层。

小字清单：`准确内容｜用途｜位置/层级｜直接生成或后期合成｜依据/待核项`。最终标题建议可以单列，但不要让图像模型烘焙进底图。

## 横竖版

16:9主体通常放上部/上中部，中下部留标题兼容区，底部有余量。3:4重新组织主体到上半/上中，下半部给标题；必须独立重构，不能拿横版中心裁切冒充竖版。

## 默认审美

未指定时优先科技媒体编辑设计 / Photoshop手工合成 / 简约平面或半平面2.5D。不要自动变成电影海报、游戏海报、旅行拼贴、满屏HUD或大量护照/地图/飞机符号。真实产品优先真实资产合成。
