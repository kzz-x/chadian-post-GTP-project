# 005｜消费电子信息场

- **适用**：手机、芯片、眼镜、接口、充电器、AI 硬件的产品展示与参数解释。
- **核心视觉公式**：准确产品英雄图＋功能定位＋外围克制参数场，产品始终是中心。
- **构图**：产品主体占据关键视觉，标签避开核心轮廓和识别部位；引线连接具体功能，参数成组而非环形围满。
- **色彩**：产品真实色优先，深青/蓝黑或干净中性色作环境；青蓝/绿少量提示功能，黄色只在需强调时用。
- **材质**：准确玻璃、金属、工程塑料与屏幕；电路/PCB 仅在与当前功能有关时作为次层。
- **光线**：有来源的棚拍产品光，轮廓与表面可读；屏幕/接口发光必须有功能解释。
- **排版 / 图形**：DIN 类数字、清楚无衬线与等宽标签；参数、单位、图标统一，真实 UI 和 Logo 用原资产。
- **镜头**：产品英雄角度、微距功能局部、有限视差；定位变焦前后有明确空间对应。
- **动态**：产品到位→扫描定位→参数显现→停留；数据流只用于真正需要说明的路径。
- **禁忌**：随意加接口、假 UI、随机电路背景、产品全透明、每个零件发光、信息压住品牌识别。
- **AI 生成约束**：具体型号先取可靠参考，锁轮廓/配色/结构；生成不可见面标推断。视频光照可连续变化，外观与标识不可漂移。
