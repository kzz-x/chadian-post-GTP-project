# 004｜电影级插画海报

- **适用**：行业寓言、游戏/影视类比、概念开场与情绪封面；不适合承担精确产品外观证据。
- **核心视觉公式**：强轮廓主角＋前中后故事空间＋一套明确色彩叙事，形成一张可停留的插画海报。
- **构图**：中心/三角/斜向聚焦，主角轮廓一眼能认；前景引导、中景动作、背景交代环境，细节服从主冲突。
- **色彩**：一到两种主色加有限对照色，可用冷暖叙事但不默认全蓝橙；主体与背景明度分开。
- **材质**：受控笔触、插画质感、印刷颗粒；不要把插画、摄影、塑料三维随机混成一层。
- **光线**：戏剧主光、边缘光与有限气氛层，主要光区指向故事核心；暗部保留层次。
- **排版 / 图形**：可选电影感衬线/重黑体，与主题一致；最终标题后排，边缘小标签少用。
- **镜头**：英雄式中/广景，机位表达人物与环境关系；静帧成立后才轻微视差，少量推进。
- **动态**：海报分层、光影缓变、局部动作；一次只动主要关系，不让全场漂浮成幻灯片特效。
- **禁忌**：无主题电影烟雾、游戏广告式堆角色、过度锐化、人物/产品身份错误、标题占位挤走主视觉。
- **AI 生成约束**：人物肢体与物体数量明确；寓言/重建不能充当真实事件照片。连续帧保持角色造型、场景比例和插画笔触。
