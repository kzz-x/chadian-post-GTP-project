# 000｜轻液态玻璃粗野酸性竞速机能 UI

- **适用**：硬件评测、消费电子参数、排行榜、数据图表、发布会信息视觉、VibeMotion 母版与科技封面。不是所有题材的强制皮肤。
- **核心视觉公式**：轻液态玻璃/毛玻璃的通透层次＋粗野压缩字的硬信息＋少量酸性警示色与竞速编号；“轻、薄、清楚”先于折射炫技。
- **构图**：一处产品/数字主焦点，非对称但对齐明确；卡片层次少而有关系，留出呼吸和稳定文字面。巨字、参数、细标签形成三级，玻璃不把画面切成等权的圆角卡片墙。
- **色彩**：白主题用冷白、雾灰、银白；黑主题用深炭黑、石墨黑。中性色为主，冷色信息、酸绿/黄绿等少量高亮作强调。可参考中性约70%、玻璃层约20%、冷色约8%、警示约2%的视觉分工，不机械测面积或同时用齐所有色。
- **材质**：薄半透明卡片，轻微毛玻璃模糊与可解释反射；边缘厚度克制，不做厚水晶、果冻或软胶。保留硬边/小圆角与清楚轮廓，卡片底与后方内容有真实层级。
- **光线**：白主题卡片内部有极淡、宽而柔的微软式渐变光流；黑主题卡片后可有大面积柔渐变辉光，亮度集中于结构分离，不给每条边加霓虹。高光随层面合理变化，文字层不被光影穿透。
- **排版 / 图形**：压缩黑体/粗黑体主标题，DIN 类窄体或等宽数字，中文选完整且清楚的黑体。机能标签、刻度、编号和短线只表达内容层级；无意义代码/伪参数不要上屏。准确字后排。
- **镜头**：信息画面默认正面固定；必要时轻微推进或层间视差，幅度不能改变读数与排列。产品可有独立三维角度，文字仍稳定。
- **动态**：系统启动/框架定位→卡片短促切入→标题硬切→数字滚动或线条生长后锁定→内部光与辉光低幅缓动。每阶段一个主动作，读取阶段安静；速度线/故障只点到为止。
- **禁忌**：默认蓝紫霓虹、厚透明水晶堆、全屏软圆角、强扭曲文字、全边描光、过量彩虹、手写/书法主字体、均匀粒子铺满、所有层不停漂浮。
- **AI 生成约束**：画面 Prompt 明确“薄而受控的玻璃、硬信息层级、低饱和底色、极少强调色”；不要同时要求高透明与大面积高密不透明发光。静帧锁卡片边界和主视觉，视频保持几何与文字位置。代码实现可用半透明层与 backdrop blur，轻扰动/边缘约1–2px低透明色散仅在必要时加入；这是效果参考，须按实际输出尺度调整，不能让滤镜扭曲数据。
