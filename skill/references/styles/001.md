# 001｜粗野未来拼贴

- **适用**：科技争议、硬件观点、行业趋势、参数冲突、强态度开场和封面。
- **核心视觉公式**：硬边网格＋产品/人物切片＋金属与像素反差＋少量强色冲击，像有意编辑的工业拼贴。
- **构图**：非对称分屏、错位但有基准的网格；一个主切片，材质区、标签区、强调区从属于它。裁切和遮挡要利落，避免碎片均匀散开。
- **色彩**：近黑、炭灰、冷黑蓝与银白主导，青或酸色作为约10%–20%的冲击参考；强调色少而集中。
- **材质**：金属、哑黑、像素/印刷面选两三类，硬质层面与清楚切边；细纹理不覆盖识别特征。
- **光线**：主主体硬朗主光和有限轮廓光；平面拼贴层用统一投影逻辑，不给每片独立光源。
- **排版 / 图形**：DIN/Bebas 类窄体、中文重黑体、等宽小标签；粗细对照、局部巨字、工业编号，信息必须有意义。
- **镜头**：以平面正视、产品局部和硬裁切为主；轻视差即可，不以环绕三维抹平拼贴感。
- **动态**：硬切、网格滑移、遮罩切片、短促吸附和到位停住；故障限定边缘或转场，主体读取期稳定。
- **禁忌**：软萌卡片、过多圆角、果冻弹性、所有材料同亮、满屏随机故障、没有语义的碎片堆积。
- **AI 生成约束**：保留抠图边界、网格与材质分区，不熔成写实场景；产品身份与文字独立核验。视频不能让切片随机增殖、Logo 变形。
