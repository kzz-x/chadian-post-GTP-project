# 006｜高密度观点缩略图

- **适用**：观点、争议、辟谣、消费警示、行业吐槽和高识别封面。
- **核心视觉公式**：一个大主体/主体组＋单一观点冲突＋强弱分明的标题环境；密度来自信息组织，不是东西多。
- **构图**：大近景与受控切边，背景满版但层级更低；标题区域依【差点封面】的用户横竖示意，不能恢复旧固定下方比例。
- **色彩**：黑/深灰与强对照色，红、绿、黄中按主题选一两个强调；文字区要与标题方案形成清楚反差。
- **材质**：真实图/三维图的手工抠图合成，适量硬描边、投影、印刷纹理；主体各层统一颗粒与明暗。
- **光线**：主体亮暗块明确，局部冲突可用定向光，不用全屏泛光抹平硬合成感。
- **排版 / 图形**：Impact/Anton 类重窄体与中文重黑体；少行短标题，辅助标签极少，AI 底图不烘焙最终字。
- **镜头**：静态封面为主，缩到约10%仍可认主体；片内化时使用有限推拉和近景，关系不变。
- **动态**：短冲击进入→标签出现→锁定；读取时安静，不持续弹跳和频闪。
- **禁忌**：三个以上竞争主体、伪造表情/破损、无依据的“实锤”、密集乱码、全图同饱和、廉价发光描边。
- **AI 生成约束**：真实品牌身份核对，冲突不造假；把标题可读区作为低冲突背景而非空白洞，横竖版重新构图。
