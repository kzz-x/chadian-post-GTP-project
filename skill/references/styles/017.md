# 017｜暗黑剪影概念叙事 CGI

公式：**匿名哑光人物剪影 + 可辨极简三维舞台 + 一组戏剧主光 + 一个符号化动作。**

观众必须看懂什么地方、有几个人、谁在做什么、人和空间是什么关系。

场景：用门、窗、桌、机器、台阶、队列等3–5个锚点建立空间，不做“纯黑背景上的人形”。

人物：无脸、无皮肤细节、哑光石墨/深灰体块，保留姿态和衣着轮廓，不是反光黑塑料玩偶。

光线：一扇窗/门/顶灯/聚光等可解释主源，亮区集中于主行为；薄雾只用于显示距离和光路，不遮挡错误场景。

动态：一次极简动作，如递文件、转身、进入、按下控制、望向光源；或只靠镜头揭示关系；动作结束后留停顿。

禁止：真人脸、超级英雄/恐怖游戏感、黑塑料高光人偶、全黑无场景、霓虹赛博HUD、浓雾遮关系、随机增加人物/肢体。

历史/商业场景必须标：**概念重建 / 叙事再现，不能冒充真实录像。**
