# 010｜复古光谱扫描

- **适用**：通信、信号、旧科技、光学、太空、系统异常和复古未来抽象镜头。
- **核心视觉公式**：高反差黑白主体＋一条有方向的光谱/扫描机制＋有限模拟信号痕迹。
- **构图**：主体结构清楚，扫描带沿确定方向穿过；水平切层、重复曝光层服务信号过程，不能占满整幅。
- **色彩**：黑白灰为底，局部光谱为唯一强彩色；克制彩虹范围，让扫描位置有辨识度。
- **材质**：胶片/模拟屏幕颗粒、扫描线、轻拖影；不同噪声尺度统一，不把画面糊成旧录像污块。
- **光线**：高对比影像与扫描发光分离，光谱经过才出现对应变化；主体暗部仍可认。
- **排版 / 图形**：VT323/Courier 类等宽信号标签配可读中文；读数必须有依据，无需数字时不用伪仪器 UI。
- **镜头**：固定屏幕/正视或有限局部推进；稳定参照便于观众感知扫描过程。
- **动态**：扫描经过→短拖影/错层→回到清楚画面；模拟抖动只短时出现。
- **禁忌**：全图彩虹、连续强频闪、黑白主体不见、现代玻璃卡片混贴、随机数字冒充检测结果。
- **AI 生成约束**：主轮廓不随扫描熔化；光学隐喻标为示意，不能声称是真实测量。视频明确扫描方向、次数与停止状态。
