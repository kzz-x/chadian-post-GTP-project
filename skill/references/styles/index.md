# 【差点风格】索引与调用规则

本文件只负责选卡和风格冲突处理，不包含各卡正文。用户指定编号时无需先读本索引，直接读取对应 `styles/<编号>.md`；只有用户未指定、当前任务确实需要自动选风格时才读取本文件。

## 风格落实

先内容关系后风格。用户指定编号优先；没有指定时，常规硬件信息视觉可从000起选，说明类可选002，真实材质/商业CGI优先016，场景关系叙事可选017。不得因“科技”二字默认蓝紫霓虹。已有批准母版优先复用。

一镜头一张主卡；必要时只补一种明确手法，例如017的叙事舞台＋016的建模/布光完成度，不能把两卡所有特征平均混合。参数与色彩比例是视觉参考，不是每张图必须逐项凑齐的硬配额。精确标题、数据、Logo优先使用可编辑/真实图层。

在B阶段，选定风格后应交：`编号/卡名｜为何适合当前关系｜构图/主辅色/材质/主光/图形/动作的具体选择｜本镜头不采用的风格特征｜参考与确认项`。选中正确编号不代表成品已经做到该风格，必须在构图、材质、光照和层级中真正落实。

风格里的巨字、标签、编号只是视觉手法，不能覆盖封面“无最终大标题/乱码/杂乱文字”的任务规则；允许少量准确相关小字，但不能机械照搬整张风格卡的标签系统。
