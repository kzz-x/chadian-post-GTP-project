# 011｜复古系统故障界面

- **适用**：软件 Bug、平台机制、账号/隐私问题、旧互联网和系统异常叙事。
- **核心视觉公式**：旧系统窗口的明确操作关系＋局部像素故障＋一个可读的主状态。
- **构图**：主窗口先成立，少量次级窗口层叠；错误/状态集中一处，不能弹窗均匀铺满。
- **色彩**：系统灰、灰青、黑、经典蓝按主题选用，少量绿/紫作状态色；不默认现代霓虹渐变。
- **材质**：像素边、硬边框、ASCII/点阵与轻屏幕颗粒；不要厚玻璃阴影或写实金属窗口。
- **光线**：屏幕自发光和浅层级，不搭三维棚拍灯光；主体窗口对比清楚。
- **排版 / 图形**：Chicago/VT323/等宽系统风与可读中文黑体；菜单、错误文案有实际语义，重要字独立排版。
- **镜头**：固定屏幕平面，必要局部定位放大；无意义旋转会破坏系统感。
- **动态**：窗口弹出→像素错位/短错误反馈→冻结让人读；低帧感可作为局部动作方式，不能持续闪烁妨碍阅读。
- **禁忌**：现代圆角玻璃 UI、随机错误代码、伪造真实软件截图、每秒无限弹窗、完全不可读的乱码。
- **AI 生成约束**：机制示意与真实 UI 分开；若讲真实操作使用可靠截图和准确步骤。视频保持窗口位置、文字、数量受控，不随机生成新按钮。
