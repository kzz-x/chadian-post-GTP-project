# 007｜几何切面叙事海报

- **适用**：行业趋势、抽象概念、科普章节、轻量开场和竖版包装。
- **核心视觉公式**：有限几何形状＋两三块主色＋清楚方向/尺度关系，以平面切面讲事。
- **构图**：圆形、斜切面、轨道或抽象地形建立主轴；一个焦点，几何大小与位置对应概念。
- **色彩**：奶白配红蓝、黄绿或橙黑等有限组合，先选主色与冲突色，不把全部色板用齐。
- **材质**：平面纸张/印刷与低强度颗粒，形状边缘清楚；不混厚金属与液态玻璃。
- **光线**：平面均匀光或轻纸面阴影，明暗主要由色块设计，不追求写实三维灯光。
- **排版 / 图形**：Futura/Montserrat 类几何无衬线和合适中文黑体；排版遵守主轴，图形须有语义。
- **镜头**：正视平面，保持整体形状可读；必要时随阅读顺序平移。
- **动态**：遮罩切换、几何滑移、圆弧旋转，到位停住；可选低帧感动作采样，输出帧率仍按项目。
- **禁忌**：无意义圆球漂浮、彩色积木堆、柔糊渐变、过量景深、没有内容映射的装饰几何。
- **AI 生成约束**：锁几何边界与主色，图形不能随机变形；精确文字/图表比例后期实现，不让生成误差替代数据。
