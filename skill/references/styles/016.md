# 016｜人工 CG 渲染

- **适用**：消费电子商业 CGI、芯片/算力/存储概念、三维结构解释、视觉重构、封面底图、图生图/图生视频与粗动效最终渲染。
- **核心视觉公式**：有设计意图的硬表面建模＋有限且清楚的 PBR 材质＋专业人工布光＋虚拟摄影机。目标是“像三维艺术家精心做出的渲染作品”，不等于原图写实翻版。
- **构图**：以文案关系和主体识别为锚，自主设计主次、前后空间、尺度和遮挡。可用悬浮、爆炸结构、阵列、切面、几何底座，但必须表达内容。用户要求重构时，不照抄原图机位/摆放/背景；要求保留时明确锁定项。爆炸结构必须还能看懂零件归属。
- **色彩**：中性色与产品色为主，限定一套主色和一个强调；保留金属、塑料、玻璃自身色响应。冷暖可用于布光分层，不全场蓝紫霓虹，不用过曝洗掉材质。
- **材质**：造型具有可理解的挤出、内凹、布尔、阵列与统一小倒角；结构细节有功能依据，主尺度与微细节分明。常用哑光工程塑料、喷砂/阳极金属、陶瓷、烟色玻璃等，通常两三种主材质足够。金属度、粗糙度、折射率、透射、厚度与吸收有明确区别；微表面变化用于控制高光，不以随机划痕污渍冒充真实。玻璃有壁厚，金属不是带灰颜色的塑料。
- **光线**：主区域光建立体积，弱补光保暗部，必要轮廓光分离主体，背景光独立克制。灯光像能摆出的 Studio Light Rig，每个主要高光有来源。接触阴影位置正确，AO 只加强接缝不涂黑所有角落；反射形状有设计感。GI 与反射/折射干净，亮部平滑回落，可参考 ACES/Filmic 的观感但不能声称实际用了某渲染器/色彩流程。
- **排版 / 图形**：字、Logo、技术标注尽量独立图层，准确字体与识别特征优先；说明引线对应真实或明确示意的部位。造型表面不塞随机机械编号、虚构电路和“技术感”乱码。
- **镜头**：产品可参考50–100mm观感减少畸变，关系夸张时才选24–35mm广角观感；工程解释可用正交。焦段是视觉指导，不是假称图像带有真实相机参数。景深服从主体清晰和物理焦面，不能把边缘选择性糊掉掩盖结构。
- **动态**：Dolly/Truck/Orbit/Crane 选一种有意义的主运动，或让物体完成一次展开、聚合、旋转到位；克制惯性，留终态。模型拓扑、厚度、数量和贴图稳定，阴影/反射随运动合理连续变化；不能为了“稳定”冻结所有反射。
- **禁忌**：照抄原图当重构、摄影写实替代人工三维设计、随机机械细节、无限倒角、果冻金属、无壁厚玻璃、过曝 Bloom、所有边自发光、过量真实环境杂物、模糊遮错、伪称真实技术拆解。
- **AI 生成约束**：先列必须保留的身份/关系，再明确可重设计的构图、造型、机位、材质和灯光；不写互相冲突的全保留/全重做。粗动效仅给运动与布局，锚点给最终外观。真实产品细节先核参考，内部不可见结构只作明确示意。首帧到尾帧锁几何、Logo/字的外置策略和主光方向；画面不因“像人工渲染”而强加噪声、污渍或照片感。
