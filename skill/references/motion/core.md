# 差点动效｜核心

职责：参数、数字、结构、流程、时间线、产品信息、数据图表、HTML/VibeMotion、Remotion、AE、三维/伪三维信息动画、可编辑工程。

## 制作顺序

**静态构图 → 动画 → 必要运镜 → 材质/粒子/光效**。静态不成立，不靠运镜救；一个阶段一个主动作，读取阶段安静。

## B固定设计卡

`镜头/目标｜依据/约束｜静态布局/读图顺序｜主次图层｜数据/单位/口径/来源缺口｜起始/变化/终态/停留｜画幅重排｜资产/技术路线｜必须可改项目｜保存/重开方式｜实际验证办法`

## 最小有效技术路线

参数卡/文字/常规流程→HTML/CSS/SVG+单一时间轴；精确图表→SVG+D3/可主题图表库；大量二维粒子→Canvas/Pixi等；真三维结构→Three.js/R3F等；程序化逐帧视频→Remotion或对应逐帧方案；用户明确AE→可编辑AE工程/脚本。不要为一层玻璃背景默认引入三维。
