# 【差点质检】

先问三件事：**讲对了吗？一眼看懂吗？真的能用吗？**

## 阶段检查

A必须有全文逻辑、总览、逐镜头八项卡、待核项；不应出现外搜结果、成图、工程。B必须有当前对象完整设计和完整Prompt/工程约定；不得未授权生产。C必须有实际成果、Prompt/配置、实际检查和缺口。D对模糊“不好看”必须给具体问题、影响、改法和保留项。

## 通用画面检查

优先级：内容/关系 → 主视觉 → 构图/层级 → 色彩/字体 → 材质/光线 → AI味 → 动效 → 真实性。先修最多三个主要问题。

## 按媒介检查

素材：画面候选/事实来源分开，未看不写时间码，访问程度真实。元素：边界完整、alpha真实、数量/视角正确、拆分状态真实。片段：锚点先成立，身份/数量/光源/运动连续，粗动效最终外观有实质升级。图表：来源/单位/口径正确，百分比/百分点正确，轴和透视不误导，dataConfig可改。工程：真能打开、改值、seek、保存重开、操作图层/面板，导出无错误控件/字体/画幅。封面：缩略图主体和冲突清楚，无最终大标题误烘焙，无乱码/无关字墙，小字准确从属，横竖不是机械裁切。

## 未测就是未测

文件结构检查≠Agent行为实测；代码静态检查≠宿主运行；Prompt检查≠成品画面合格；规则写进Skill≠已通过回归。
