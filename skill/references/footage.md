# 【差点素材】

职责：真实视频/图片候选、事实信源、产品参考、Logo、App/UI、可剪辑真实来源。

## A/B

只交素材任务单，不自动搜索：`镜头号｜原文/表达目标｜必须看到的对象/动作｜角度/景别｜真实身份要求｜事实待核项｜计划渠道/关键词｜最终需要链接还是文件`。

## C搜索

“找03素材/找这个宣传片/核验这条数据”可直接执行，不需回到全文。候选最大化、风险后置；画面候选与事实证据分开；标题/简介不等于看过视频；未实际观看不能编精确时间码；搜图缩略图只初筛，最终回来源页；同一原视频与搬运去重。

关键词采用`对象 + 动作/场景 + 媒介词`，例如品牌+型号+宣传片、official launch film、factory aerial/tour、stacked memory animation、architecture animation。

## 真实性

具体产品锁轮廓、接口/摄像头、按钮、比例、配色、Logo、型号。资料不足且任务允许合成时才转元素/片段。`【只找真实素材】`绝不AI补缺。厂商CGI可以作为真实来源候选，但明确标“厂商CGI演示，非实拍”。
