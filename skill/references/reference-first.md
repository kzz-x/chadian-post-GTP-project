# Reference First｜参考驱动制作

适用于具体镜头、封面、动效、CGI、AI片段、视觉元素和真实素材方案。核心原则：

**先找参考 → 拆解参考 → 决定制作路径 → 再设计/执行。**

参考不是装饰，也不只是“给 AI 看”。它用于约束主体准确性、构图、材质、运动规律、节奏、镜头语言和最终制作路线。

## 阶段边界

- A｜全文分析：仍然不外搜。只标记“该镜头后续需要什么参考”。
- B｜指定对象设计：参考搜索属于设计的一部分，可以主动搜索和整理参考；找参考不等于授权进入 C 制作。
- C｜指定制作：优先使用 B 已锁定参考；若关键参考缺失，先补参考或使用明确标注的可替换占位，不要凭空伪造精确产品/结构/动作。
- 用户明确说“不要搜参考 / 直接按我给的参考 / 只按现有素材做”时，以用户要求为准。

## 先判断需要哪类参考

1. **主体 / 身份 / 结构参考**
   - 真实产品、零件、设备、UI、Logo、人物、建筑、机械结构。
   - 约束“它到底长什么样、结构是否正确”。

2. **视觉 / 风格参考**
   - 构图、版式、字体关系、材质、灯光、色彩、信息密度、合成手法。
   - 约束“画面应该怎么组织”。

3. **动效 / 节奏参考**
   - 视频、GIF、Lottie、AE案例、广告片、UI motion、HUD动画。
   - 约束 Timing、Spacing、Ease、Stagger、Overshoot、Follow Through、转场和镜头运动。
   - **静帧不能证明运动规律；明显运动任务不要只找图片参考。**

4. **真实运动 / 物理规律参考**
   - 人、手、动物、液体、金属、布料、机械机构、装配、碰撞、跌落等真实视频或成熟动画。
   - 类生物运动、复杂机械、物理现象优先真实视频 / 成熟案例，不让 AI 凭空编动作。

5. **可直接复用资产**
   - 官方 PNG / SVG、Lottie JSON、透明通道素材、视频素材、图标、3D、模板。
   - 能直接复用成熟资产时，不强制 JSX / AI 从零重画。

## 强制触发

以下任一出现时，默认先补参考：
- 品牌/产品/零件/设备外观必须准确；
- 结构、装配、机械关系不能错；
- 人物、手、动物等类生物运动；
- 液体、金属融合、破碎、碰撞等物理现象；
- 用户要求“像某种成熟动效 / 广告 / UI / HUD”；
- AI 连续两次画错结构、动作或材质；
- 现有方案“能动但不自然 / 像模板 / 一眼 AI”；
- 存在可直接复用 Lottie / SVG / 视频 / 官方素材的可能。

普通文字淡入、简单数据增长、几何路径、已有图层的小 Patch 不必为了流程强搜参考。

## 来源优先级

优先：
1. 官方网站 / 官方发布素材 / 产品页 / 技术文档；
2. 真实实拍、品牌广告、发布会、纪录片、成熟商业成片；
3. 专业设计 / 动效案例与可信资产库；
4. 高质量社区案例；
5. AI 生成参考只作概念辅助，不能替代需要准确性的真实参考。

产品相关优先真实官方图；找不到时可使用高质量占位，但必须明确后续替换。

## Reference Brief｜参考摘要

进入正式设计前，按需整理 2–6 个真正有用的参考，不追求堆数量。每个参考说明：

`参考 → 用来约束什么 → 哪部分借鉴 / 哪部分不要照搬`

动效任务至少覆盖：
- 视觉静帧或主体参考；
- 一条能说明运动规律 / 节奏的视频、GIF、Lottie 或成熟动效案例（若运动是重点）。

## 参考决定制作路径

找到参考后，不默认“照着画”，先选最省返工的路线：

- **直接复用**：官方 PNG / SVG / Lottie / 视频 / 模板已经足够好；
- **AE 重建**：借参考的构图、节奏、运动逻辑，用原生 AE / 表达式 / 关键帧重建；
- **Hybrid**：真实主体素材 + AE 信息层 / HUD / 背景 / 动效；
- **AI 生成**：只生成背景、氛围、不可考据部分，准确主体后期替换；
- **概念占位**：关键参考暂缺时，先做可替换结构，不把占位当最终事实。

## 缺参考时

如果关键参考缺失：
- 主动搜索；能找到真实参考就不要凭空发明；
- 搜不到时明确写“概念示意 / 待替换 / 结构未核验”；
- 需要准确产品时优先提醒用户提供官方图或允许后期 PS / AE 替换；
- 不因缺素材而用低质量 Shape、伪产品、错误机械结构或随机 AI 细节填坑。

最终目标不是“每次都多搜一步”，而是：**凡参考能显著降低返工、提高真实性或改善运动质量，就先用参考约束 AI 的自由发挥。**
