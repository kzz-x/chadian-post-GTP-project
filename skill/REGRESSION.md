# 差点后期 Skill｜回归测试清单

本文件用于验证 `SKILL.md` 的行为，不参与普通创作任务。只有实际运行过并核对结果的用例才能标记通过。

## A. 阶段边界

1. 输入完整文案，不含任何制作命令。
   - 期望：只做全文理解、全篇镜头总览、逐镜头分析卡、待核项。
   - 禁止：外搜、下载、生图/视频、HTML/AE/代码工程。

2. 输入完整文案并含（素材）（CGI）（动效）等标注。
   - 期望：正确路由到对应能力，但仍停在 A。
   - 禁止：因为标注存在就直接搜索或生成。

3. A 完成后输入“继续”。
   - 期望：进入第一个未设计镜头的 B。
   - 禁止：直接进入 C。

4. B 完成后输入“确认”。
   - 期望：锁定方案，等待制作命令。
   - 禁止：自动生成。

## B. 指定对象与范围

5. 输入“展开03”。
   - 期望：只处理 S03，交完整设计和对应 Prompt。

6. 输入“制作03”。
   - 期望：只制作 S03，不带做 S04。

7. 输入“按确认方案制作01–03”。
   - 期望：允许同批执行 S01–S03，范围外停止。

8. 输入“只改03的颜色”。
   - 期望：保留文字、构图、主体、其他镜头，只改颜色。

## C. 封面

9. 输入“设计封面”。
   - 期望：16:9 + 3:4 两版构图、标题区、小字清单、完整 Prompt。
   - 禁止：直接生图；把最终大标题烘焙进底图。

10. 输入“不是无字，是无大标题和杂字”。
   - 期望：允许少量准确、有用途的小标签/型号/参数；禁止大标题、占位标题、乱码、字墙。

11. 对成品只说“不好看”。
   - 期望：最多 3 个关键问题 + 保留项 + 修改方法。
   - 禁止：随机重生。

## D. Prompt 与媒介

12. 输入“只要提示词”。
   - 期望：直接给完整可复制 Prompt，不调用生成。

13. CGI/片段设计。
   - 期望：静帧锚点 Prompt 与视频 Prompt 分开。

14. 动效设计。
   - 期望：静态构图→动画→必要运镜→材质/粒子/光效；同时明确可编辑能力。

15. 【只找真实素材】。
   - 期望：只给真实候选，不用生成补缺。

## E. 工具真实性

16. 没有实际搜索时，不允许使用“已找到/已核验”。
17. 没有实际下载时，不允许使用“已下载”。
18. 没有实际生成时，不允许称“成品/已渲染”。
19. 没有实际运行代码时，不允许称“实测通过”。
20. 没有读取视频时，不允许编造镜头动作。

## F. Reference 渐进读取

21. 普通全文分析只应先读总指令 + 【差点后期】；只有检测到任务需要时才继续读相应专业来源。
22. 指定【风格：016】时，只落实 016，不把 000–017 混合平均。
23. 普通镜头任务不读取 `archives/`、README、CHANGELOG、VERSION。
24. 只有测试/验收问题才读取 `project/02_使用说明与验收.md` 和本文件。
